# P4 자동설계 설계 — Milky · LED 개수/피치 · LGP 형상 (체크한 항목만 최적화)

- 날짜: 2026-10-19
- 선행: `2026-10-14-3d-line-light-design.md` §6.2–6.3(재사용 개념), `2026-10-15-m3-cad-ui-design.md`(CAD식 화면·점진 계산), P1~P3·UI 구현
- 대상: 3D 기구 모드

## 1. 결정 사항 (사용자 확정)
- **우선순위:** 균일도 목표(길이·폭 U) 만족이 기본 조건이다. 그다음 ① **LED 개수 최소**, ② **밝기 최대**(같은 개수면 Milky 최소) 순으로 고른다.
- **단계 선택(체크박스 3개):** 체크한 항목만 바꾸고, 체크하지 않은 항목은 현재 값으로 고정한다.

| 체크 | 최적화 | 비고 |
|---|---|---|
| ① Milky 레벨 | 목표를 만족하는 최소 Milky | 커버(Milky 부품)가 있어야 함 |
| ② LED 개수·피치 | 목표를 만족하는 최소 개수(그 개수에서 ①이 켜져 있으면 최소 Milky) | 광원이 "직접 배치"일 때만. LED STEP 은 위치가 고정이라 비활성 + 안내 |
| ③ LGP 형상 | 주어진 Milky·피치에서 목표를 만족하는 후보 중 휘도 최대(만족 후보가 없으면 min(U길이/목표, U폭/목표) 최대) | 사용자가 고른 부품 1개. 관측 방향으로 2.5D 인 부품만 |

- **실행 순서(여러 개 체크):** ② → ① → ③.
- **③ 형상 변수:** 전체 두께 오프셋 Δt, LED 위 국부 형상(깊이 h: + 포켓 / − 돌출, 반경 R).
- **결과 적용:** 현재안과 최적안을 오른쪽 결과 패널에 나란히 비교한 뒤 [적용]/[취소]. 적용 직전 상태를 저장해 [되돌리기] 버튼으로 복원한다(현재 앱에 실행 취소 기능이 없음).
- ③ 결과는 목업용 STEP 으로 내보낸다.

## 2. 방식 (재사용 + 단계적 압축)

### 2.1 ① Milky — 재가중
- 계산 중 광자마다 Milky 부품 안에서의 **경로 길이 L 과 산란 횟수 k** 를 누적한다.
- 관측면으로 집계되는 탈출마다 Milky 격자 j(기준 Milky m₀ 주변 ±0.25, 21점, 0.025 간격) 의 가중치를 곱해 동시에 집계한다:
  `f_j = (μs_j/μs₀)^k · exp(−((μs_j+μa_j) − (μs₀+μa₀))·L)`
  Milky = 입자 농도이므로 μs·μa 가 함께 비례하고(DB 소재는 μa 수지분 제외, P2 규칙), 위상함수는 그대로다.
- 기준점에서 멀어지면 분산이 커진다. 실측(Milky 판): Milky 1 차이에 μs 가 약 2.2배라 ESS 0.3 이상인 범위는 기준 ±0.25 안팎뿐이다(2.0→0.04, 2.5→0.32, 3.25→0.35, 3.5→0.05). 그래서 창은 ±0.25 로 두고, ESS 0.3 미만 격자점은 버린다.
- 탐색: 창 안에서 목표를 처음 만족하는 최소 Milky 를 선형 보간으로 찾는다. 창 전체가 통과하면 더 낮은 쪽, 전부 미달이면 더 높은 쪽으로 **이분 탐색**으로 기준을 옮긴다(구간 [0.25, Milky 상한], 최대 8회). → 그 Milky 로 정밀 재계산해 판정.

### 2.1a ① "균일도 우선" (2026-10-20 개정, 사용자 확정)
- 의도: ① 만 체크해도 Milky 로 균일도를 최대한 확보한다(투과율·광량은 희생). 목표 도달이면 그 최소 Milky, 아니면 균일도가 가장 높은 Milky 를 추천하고 한계·원인·보완책을 숫자로 보인다.
- 실측(샘플, 케이스 백색 85 %): Milky 2/3/4/5/6/7/8 → 길이 U 0.65/0.70/0.72/0.65/0.58/0.54/0.52, 폭 U 0.61/0.65/0.66/0.60/0.58/0.53/0.55, 효율 70→25 %. **U(Milky) 는 단봉형** — 높은 Milky 에서 빛이 커버 안에서 옆으로 오래 머물며 케이스 벽(85 %)에 흡수돼 가장자리·끝단이 어두워진다(가장자리 감쇠).
- 탐색: ① 거친 탐색 — Milky 0.5, 1.5, 2.5, 3.5, … 를 차례로(시간 예산 추적), 여유 margin = min(길이 U−목표, 폭 U−목표) 가 최고점을 지나 두 번 연속 떨어지면 멈춤. ② 최고점 주변 재가중 창(±0.25)으로 정밀 최고점. ③ 최고점 margin ≥ 0 이면 오르는 구간 [0.25, 최고점] 에서 기존 창+할선/이분 탐색으로 최소 통과 Milky. 아니면 최고점 Milky 를 "가장 가까운 안" 으로.
- 상한: ① 만 체크하면 9.9(카드의 상한 입력이 있으면 그 값). ② 와 함께면 ② 의 기준 Milky 는 기존 상한(기본 5) — 계산 시간.
- 한계 안내: 최고점에서 막는 쪽(길이/폭)과 최저 위치가 가장자리·끝단(전체 폭/길이의 바깥 15 %)이면 "가장자리 감쇠", 아니면 "LED 리플". 보완 계산: ④ 가 가능하면 최고점 Milky 에서 케이스 면 한 단계 위(현재보다 높은 등급 중 가장 낮은 것)를 한 번 계산해 "④ 케이스 ○○ 와 함께 쓰면 길이 U a · 폭 U b" 를 보인다(가능하지 않으면 생략).

### 2.2 ② LED 개수·피치 — 후보 위치 응답 합산
- 관측 라인을 따라 **후보 위치(간격 1mm, 열린 라인은 양 끝 포함, 닫힌 라인은 균등)** 마다 LED 1개의 관측면 지도를 추적한다.
- 개수 n 과 피치 p(대칭 배치, 기존 `ledSPositions` 규칙)의 지도 = 해당 후보 지도의 합(후보 사이 위치는 이웃 두 후보의 선형 보간)이다. 선형 중첩이라 근사가 없다(보간 제외).
- 탐색: n = 1 부터 늘려 가며 각 n 에서 피치(0 = 라인 전체 균등 배치, 또는 사용자 입력 범위의 1mm 간격) 중 최적을 고르고, 목표를 처음 만족하는 n 에서 멈춘다(상한: 라인 길이 / LED 크기). ①이 켜져 있으면 후보 지도를 **Milky 상한**(기본 max(현재, 5), 카드에서 조정)에서 추적해 최소 n 을 구하고, 그 n 에서 ① 이 Milky 를 낮춘다(확산 최대로 균일도 확보 → 확산을 줄여 밝기 — 사용 시나리오 L2 와 같은 순서).
- 비용: 샘플(116mm) 기준 후보 117개 × 2만 광자 ≈ 230만 광자 ≈ 35초(Worker 15개).
- 메모리: 후보 지도는 Float32 로 보관한다(배치 없이 합계만 — 노이즈는 최종 재판정이 맡는다).

### 2.2a LED STEP 가상 배치 (2026-10-20 추가, 사용자 확정)
- LED STEP 을 불러와도 개수·피치를 바꿀 수 있게 한다. 원본 STEP 은 그대로 두고 `light.step.virtual = { count, pitch } | null` 로 저장한다.
- 배치: 기준 LED(제외되지 않은 첫 LED)의 **몸체 메쉬와 발광점**을 복사해 관측 라인 위 `ledSPositions(line, count, pitch)` 의 각 s 에 놓는다. 라인 좌표 (s, w, h) 중 w(라인에서 벗어난 거리)·h(높이)는 기준 LED 값을 유지하고, 라인 접선이 기준 위치와 다르면 관측 방향 d 축으로 같은 각만큼 돌린다. 원래 LED 몸체(제외 LED 포함)는 빼고, PCB·기타 부품은 그대로 둔다.
- 화면: 피처 트리 LED 노드에 "가상 배치" 배지, LED 노드 속성에 [STEP 원래 위치 | 가상 배치] 전환 + 개수·피치 입력 + [원래 STEP 위치로]. 가상 배치 중에는 LED 제외 클릭을 쓰지 않는다.
- 자동설계 ②: LED STEP 이면 가상 배치로 동작한다. 후보 위치 지도는 LED 몸체 없이(발광점만, PCB 유지) 추적하고, 최종 재판정은 복사한 몸체를 포함한 전체 장면으로 한다. 적용 = `step.virtual` 저장.

### 2.2b ② 폭 방향 열 배치 (2026-10-20 추가, 사용자 확정)
- 근거(샘플, Milky 3): 1열 폭 U 0.65 → 2열(±4 mm, 20개) 0.88. 2열 ±5 mm·20개·케이스 95 % = 길이 0.84·폭 0.87(목표 통과). 지그재그 10개 폭 0.44(나쁨), 5쌍(10개) 길이 0.12(나쁨). V자 반사판은 폭에 효과 없음, 폭 축소 16→12 mm + 95 % = 0.78/0.81(기구 변경 — 도구 범위 밖, 참고).
- 배치 변수: 열 수 rows ∈ {1, 2}, 열 간격 δ(중심선에서 ±δ, 2열만). 두 열은 같은 s 위치(정렬, 지그재그 아님), 열마다 n 개 → 총 LED = rows·n.
- 직접 배치·LED STEP 가상 배치 모두 rows·δ 를 지원(`manual.rows, manual.rowGap`, `step.virtual.rows, rowGap`). 기본 rows 1.
- 자동설계 ②: 후보 지도를 (s, w) 격자로 — s 2 mm 간격 × w ∈ {0} ∪ {±δk}(δk = 0.2·W, 0.27·W, 0.33·W; W = 관측면 폭). 배치 지도 = 열·위치별 지도 합(보간은 s 방향만). 탐색은 **총 LED 수 오름차순**(1열 n, 2열 n/열 을 섞어 총수 기준) → 같은 총수면 1열 우선 → 피치·δ 중 최고. 1열로 목표가 안 될 때만 2열이 뽑힌다.
- 비교표: `1열 10개` → `2열 × 10개(열 간격 ±5.0 mm)`.

### 2.2c ② 를 ①·④ 와 함께 쓸 때 — 유리한 기준에서 개수 (2026-10-20 추가)
- 문제: ② 가 먼저 개수를 정하는데, 기준이 Milky 상한 5(단봉형 U(Milky) 최고점 ≈3–4 를 지나 오히려 불리하고 추적도 느림)·케이스 현재 면(④ 는 뒤에 실행)이라 개수가 과다(샘플: 2열 × 14 = 28개, 실제로는 2열 × 10 = 20개로 충분).
- 우선순위: 최소 LED 개수 → 밝기.
- ① 함께: ② 전에 현재 설계로 거친 최고점 탐색만(창 0.5, 1.5, … ≤ 상한, 최고점 뒤 처음 내려가면 멈춤, 정밀 없음) → mRef = 최고 믿는 행의 Milky. ② 기저는 d.milky = min(상한, mRef). 진행 '② 기준 Milky 찾기 (Milky m)'.
- ④ 함께: ② 기저는 케이스 면 = finishCands 중 최고 등급(가장 유리). 개수 확정 뒤 ④ 는 현재 면으로 되돌려 평가하고 통과 중 최저 등급(lowestPassing), 그다음 ① 최소 Milky.
- 둘 다 아니면 기존 그대로. 기록 steps {stage:'ledsRef', milky: mRef, finish}.
- 기저 추적: 후보마다 진행 'LED 후보 위치 추적 i/n'. 지도는 후보 자신의 방출로 나눈 방출 1 기준(emitted = 1) → 후보마다 광자 수가 달라도 됨. 전체 예산 60 s — 후보 광자 = min(12000, 처리량 × 남은 시간 / 남은 후보, ≥ 3000).

### 2.3 ③ LGP 형상 — 높이맵 변형 + 단계적 압축
- 고른 부품을 관측 방향 기준 **높이맵(윗면·아랫면)** 으로 바꾼다(기존 `heightfield.js`). 2.5D 가 아니면(비 2.5D 비율 > 2%) ③을 비활성하고 이유를 보인다.
- 변형(관측면 반대쪽 = 아랫면만, 관측 좌표 z = 관측자 쪽 +):
  - 아랫면 이동량 D(x,y) = Δt − h · Σ_LED bump(|p − c|/R)  (D > 0 = 아랫면이 내려감 = 두꺼워짐, bump = 코사인 창, r ≥ R 에서 0)
  - z_b' = z_b − D. h > 0 = 포켓(LED 위가 얇아짐), h < 0 = 돌출.
  - 방법: 자유형 변형(FFD) — 정점 p 의 z' = z − w·D(x,y), w = (z_t − z)/(z_t − z_b) (윗면 w=0 고정, 아랫면 w=1).
    원본 메쉬를 LED 원판(반경 R) 부근만 모서리 기준으로 세분(이웃 삼각형과 어긋남 없음)해 곡면을 표현한다.
- 탐색 범위(기본): Δt ∈ [−0.5·t₀, +1.0·t₀], h ∈ [−0.5·t₀, +0.5·t₀], R ∈ [0.3·피치, 0.8·피치] (LED STEP 이면 피치 = 평균 LED 간격). t₀ = 부품 평균 두께.
- 단계적 압축: 3×3×3 = 27 후보를 적은 광자(각 3만)로 평가 → 상위 6 개를 10만으로 → 상위 2 개를 정밀(잡음 ±2%)로 → 최종 1 개.
- 제약: 매 후보마다 살두께 ≥ 최소 살두께, LED 간섭 없음(점검 ①·③). 위반 후보는 버린다.
- 메쉬: 변형한 높이맵으로 삼각형 메쉬를 다시 만들어(격자 셀 = min(0.5mm, 피치/20)) 추적 장면의 해당 부품을 바꾼다. 다른 부품과의 접촉면은 변형하지 않는 면(윗면·옆면) 기준으로 유지한다.
- STEP 내보내기: 변형된 부품의 삼각형 메쉬를 꿰매 솔리드로 만들어 STEP 으로 내보낸다(`buildBodySolid` 는 사각 판 전용이라 쓰지 않음).
- 적용 저장: `spec.mech3d.parts[i].shapeMod = { frame:{u,v,d}, dt, h, R, centers:[[x,y]…], cell }`.
  런타임은 원본 메쉬 → xform → shapeMod 순서로 다시 만든다(되돌리기 = shapeMod 삭제).

### 2.3a ③ 길이·폭 방향 형상 변수 (2026-10-20 추가, 사용자 확정)
- 배경: 샘플은 폭 균일도가 막는다(어떤 Δt·h·R 조합도 폭 U ≤ 0.70). 원형 국부 형상은 길이 방향 리플만 다룬다.
- 아랫면 이동량에 두 항을 더한다(관측 좌표, D > 0 = 두꺼워짐):
  `D = Δt − h·Σ bump(|p−c|/R) + e·endW(s) + c·(w/W½)²`
  - **끝단 두께 e (길이 방향):** 열린 라인의 양 끝 구간(길이 ℓ = LED 피치)에서 endW(s) = 0.5(1+cos(π·min(s, L−s)/ℓ)) (끝 = 1, ℓ 안쪽 = 0). 닫힌 라인은 0.
  - **폭 가장자리 두께 c(mm, 포물선 분포):** w = 중심선에서 벗어난 거리, W½ = 라인 반폭, |w| > W½ 는 W½ 로 자름. c > 0 = 가장자리 두꺼움, c < 0 = 가장자리 얇음.
  - (s, w) 는 shapeMod 에 함께 저장한 중심선 폴리라인(관측 좌표, 1 mm 간격)·반폭·닫힘으로 계산 — shapeMod 만으로 형상이 결정되게.
- 범위(기본): e, c ∈ [−0.5·t₀, +0.5·t₀].
- 탐색 2단계: ① 선별 — 현재 형상 + 변수 하나씩 하한/상한(1 + 2×5 = 11개, 후보당 6만 광자)으로 효과가 큰 변수 최대 3개를 고른다(점수 향상 < 0.01 이면 제외). ② 고른 변수의 3^k 격자(≤ 27, 현재 형상 포함)를 단계적 압축(27→6→2). 고른 변수가 없으면 "형상 변경 효과 없음".
- 저장: shapeMod 에 `e, c, path:[[x,y]…], halfW, closed, ell` 추가(없으면 0 — 이전 저장과 호환).

### 2.3b 기타 개선 (2026-10-20)
- ① 시간: 점진 계산이 같은 장면에서 잡음 목표에 도달해 있으면 그 결과를 "현재안"으로 재사용한다. 탐색용 기준점은 최소 10만 광자, 다음 기준점은 지금까지의 U(Milky) 여유로 할선법(구간 밖이면 이분), 경계 창만 정밀.
- 속성 패널 크기·부피: 실제 장면 메쉬(크기·위치·형상 반영)의 외곽·부피로 표시.
- ③ STEP: 외곽이 직사각형(관측 좌표 높이맵 채움률 ≥ 0.98)이고 윗면이 평평하면 아랫면을 B-스플라인 곡면으로 맞춰(격자 표본) 솔리드를 만든다(곡면 면 돌출 ∩ 외곽 상자). 아니면 기존 삼각형 꿰매기.
- 참고(사용자 확인): 케이스(백색 반사 85%) 유무로 길이 U 0.69↔0.49, 폭 U 0.63↔0.51, 효율 70↔49 % — 케이스 반사율·형상도 이후 자동설계 대상 후보.

### 2.3c ④ 케이스 면 처리 · ⑤ LED–커버 거리 (2026-10-20 추가, 사용자 확정)
- 근거(민감도, 샘플): 케이스 백색 50/85/95 % → 길이 U 0.56/0.67/0.76, 폭 U 0.49/0.62/0.65, 효율 55/70/78 %. 경면 88 % → 0.75/0.60/72 %. LED–커버 6.5/5.5/4.0/2.5 mm → 폭 U 0.62/0.52/0.36/0.21.
- 실행 순서(체크한 것만): ② LED 개수·피치 → ⑤ LED 높이 → ④ 케이스 면 → ① Milky → ③ 형상.
- **④ 케이스 면 처리:** 대상 = 불투명 부품 하나(기본: 관측 부품을 둘러싼 가장 큰 불투명 부품, 카드에서 선택). 후보(등급 순) = 백색 85·90·95·97 %, 경면(금속) 88·95 % — 현재 면 처리도 후보에 포함. 후보마다 6만 광자 → 상위 2개 정밀. 선택 규칙: 목표를 만족하는 후보 중 **등급이 가장 낮은 것**(같은 반사율이면 백색 우선), 없으면 점수 최고. 적용 = 그 부품의 기본 면 처리(면별 덮어쓰기는 유지).
- **⑤ LED 높이(LED–커버 거리):** 관측 방향 d 로 LED 를 dz 만큼 옮긴다. 범위 = 간섭 없이 갈 수 있는 [아래 한계, 위 한계](clearance 이동 거리 − 0.3 mm 여유; 직접 배치 깊이 모드는 발광점 위아래 광선 거리 기준). 후보 7개(현재 포함) 6만 광자 → 상위 2개 정밀, 점수 최고(목표 만족 우선 → 효율). 적용: LED STEP(원래·가상) = step.offset += dz·d, 직접 배치(깊이) = pcb.depth −= dz. 직접 배치(기구 면 PCB)는 높이가 기구 면으로 정해지므로 ⑤ 비활성(이유 표시).
- 모든 단계 공통: 최종 재판정과 "현재안보다 나쁘면 유지" 규칙 적용.

### 2.4 정밀 재판정
- 어떤 단계든 최종안은 재사용·보간 없이 일반 점진 계산(잡음 목표까지)으로 다시 계산해 판정한다. 재사용 결과와 최종 판정이 다르면(U 차이 > 0.02) 표시한다.
