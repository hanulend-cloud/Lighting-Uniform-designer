# P4 자동설계 설계 — Milky · LED 개수/피치 · LGP 형상 (체크한 항목만 최적화)

- 날짜: 2026-10-19
- 선행: `2026-10-14-3d-line-light-design.md` §6.2–6.3(재사용 개념), `2026-10-15-m3-cad-ui-design.md`(CAD식 화면·점진 계산), P1~P3·UI 구현
- 대상: 3D 기구 모드

## 1. 결정 사항 (사용자 확정)
- **우선순위:** 균일도 목표(길이·폭 U) 만족이 기본 조건이다. 그다음 ① **LED 개수 최소**, ② **밝기 최대**(같은 개수면 Milky 최소) 순으로 고른다.
- **단계 선택(체크박스 3개):** 체크한 항목만 바꾸고, 체크하지 않은 항목은 현재 값으로 고정한다.

| 체크 | 최적화 | 비고 |
|---|---|---|
| ① Milky 레벨 | 목표를 만족하는 최소 Milky | 커버(Milky 부품)가 있어야 함 |
| ② LED 개수·피치 | 목표를 만족하는 최소 개수(그 개수에서 ①이 켜져 있으면 최소 Milky) | 광원이 "직접 배치"일 때만. LED STEP 은 위치가 고정이라 비활성 + 안내 |
| ③ LGP 형상 | 주어진 Milky·피치에서 목표를 만족하는 후보 중 휘도 최대(만족 후보가 없으면 min(U길이/목표, U폭/목표) 최대) | 사용자가 고른 부품 1개. 관측 방향으로 2.5D 인 부품만 |

- **실행 순서(여러 개 체크):** ② → ① → ③.
- **③ 형상 변수:** 전체 두께 오프셋 Δt, LED 위 국부 형상(깊이 h: + 포켓 / − 돌출, 반경 R).
- **결과 적용:** 현재안과 최적안을 오른쪽 결과 패널에 나란히 비교한 뒤 [적용]/[취소]. 적용 직전 상태를 저장해 [되돌리기] 버튼으로 복원한다(현재 앱에 실행 취소 기능이 없음).
- ③ 결과는 목업용 STEP 으로 내보낸다.

## 2. 방식 (재사용 + 단계적 압축)

### 2.1 ① Milky — 재가중
- 계산 중 광자마다 Milky 부품 안에서의 **경로 길이 L 과 산란 횟수 k** 를 누적한다.
- 관측면으로 집계되는 탈출마다 Milky 격자 j(기준 Milky m₀ 주변 ±0.25, 21점, 0.025 간격) 의 가중치를 곱해 동시에 집계한다:
  `f_j = (μs_j/μs₀)^k · exp(−((μs_j+μa_j) − (μs₀+μa₀))·L)`
  Milky = 입자 농도이므로 μs·μa 가 함께 비례하고(DB 소재는 μa 수지분 제외, P2 규칙), 위상함수는 그대로다.
- 기준점에서 멀어지면 분산이 커진다. 실측(Milky 판): Milky 1 차이에 μs 가 약 2.2배라 ESS 0.3 이상인 범위는 기준 ±0.25 안팎뿐이다(2.0→0.04, 2.5→0.32, 3.25→0.35, 3.5→0.05). 그래서 창은 ±0.25 로 두고, ESS 0.3 미만 격자점은 버린다.
- 탐색: 창 안에서 목표를 처음 만족하는 최소 Milky 를 선형 보간으로 찾는다. 창 전체가 통과하면 더 낮은 쪽, 전부 미달이면 더 높은 쪽으로 **이분 탐색**으로 기준을 옮긴다(구간 [0.25, Milky 상한], 최대 8회). → 그 Milky 로 정밀 재계산해 판정.

### 2.2 ② LED 개수·피치 — 후보 위치 응답 합산
- 관측 라인을 따라 **후보 위치(간격 1mm, 열린 라인은 양 끝 포함, 닫힌 라인은 균등)** 마다 LED 1개의 관측면 지도를 추적한다.
- 개수 n 과 피치 p(대칭 배치, 기존 `ledSPositions` 규칙)의 지도 = 해당 후보 지도의 합(후보 사이 위치는 이웃 두 후보의 선형 보간)이다. 선형 중첩이라 근사가 없다(보간 제외).
- 탐색: n = 1 부터 늘려 가며 각 n 에서 피치(0 = 라인 전체 균등 배치, 또는 사용자 입력 범위의 1mm 간격) 중 최적을 고르고, 목표를 처음 만족하는 n 에서 멈춘다(상한: 라인 길이 / LED 크기). ①이 켜져 있으면 후보 지도를 **Milky 상한**(기본 max(현재, 5), 카드에서 조정)에서 추적해 최소 n 을 구하고, 그 n 에서 ① 이 Milky 를 낮춘다(확산 최대로 균일도 확보 → 확산을 줄여 밝기 — 사용 시나리오 L2 와 같은 순서).
- 비용: 샘플(116mm) 기준 후보 117개 × 2만 광자 ≈ 230만 광자 ≈ 35초(Worker 15개).
- 메모리: 후보 지도는 Float32 로 보관한다(배치 없이 합계만 — 노이즈는 최종 재판정이 맡는다).

### 2.3 ③ LGP 형상 — 높이맵 변형 + 단계적 압축
- 고른 부품을 관측 방향 기준 **높이맵(윗면·아랫면)** 으로 바꾼다(기존 `heightfield.js`). 2.5D 가 아니면(비 2.5D 비율 > 2%) ③을 비활성하고 이유를 보인다.
- 변형(관측면 반대쪽 = 아랫면만, 관측 좌표 z = 관측자 쪽 +):
  - 아랫면 이동량 D(x,y) = Δt − h · Σ_LED bump(|p − c|/R)  (D > 0 = 아랫면이 내려감 = 두꺼워짐, bump = 코사인 창, r ≥ R 에서 0)
  - z_b' = z_b − D. h > 0 = 포켓(LED 위가 얇아짐), h < 0 = 돌출.
  - 방법: 자유형 변형(FFD) — 정점 p 의 z' = z − w·D(x,y), w = (z_t − z)/(z_t − z_b) (윗면 w=0 고정, 아랫면 w=1).
    원본 메쉬를 LED 원판(반경 R) 부근만 모서리 기준으로 세분(이웃 삼각형과 어긋남 없음)해 곡면을 표현한다.
- 탐색 범위(기본): Δt ∈ [−0.5·t₀, +1.0·t₀], h ∈ [−0.5·t₀, +0.5·t₀], R ∈ [0.3·피치, 0.8·피치] (LED STEP 이면 피치 = 평균 LED 간격). t₀ = 부품 평균 두께.
- 단계적 압축: 3×3×3 = 27 후보를 적은 광자(각 3만)로 평가 → 상위 6 개를 10만으로 → 상위 2 개를 정밀(잡음 ±2%)로 → 최종 1 개.
- 제약: 매 후보마다 살두께 ≥ 최소 살두께, LED 간섭 없음(점검 ①·③). 위반 후보는 버린다.
- 메쉬: 변형한 높이맵으로 삼각형 메쉬를 다시 만들어(격자 셀 = min(0.5mm, 피치/20)) 추적 장면의 해당 부품을 바꾼다. 다른 부품과의 접촉면은 변형하지 않는 면(윗면·옆면) 기준으로 유지한다.
- STEP 내보내기: 변형된 부품의 삼각형 메쉬를 꿰매 솔리드로 만들어 STEP 으로 내보낸다(`buildBodySolid` 는 사각 판 전용이라 쓰지 않음).
- 적용 저장: `spec.mech3d.parts[i].shapeMod = { frame:{u,v,d}, dt, h, R, centers:[[x,y]…], cell }`.
  런타임은 원본 메쉬 → xform → shapeMod 순서로 다시 만든다(되돌리기 = shapeMod 삭제).

### 2.4 정밀 재판정
- 어떤 단계든 최종안은 재사용·보간 없이 일반 점진 계산(잡음 목표까지)으로 다시 계산해 판정한다. 재사용 결과와 최종 판정이 다르면(U 차이 > 0.02) 표시한다.

## 3. 화면
- 명령 막대에 [자동설계] 버튼 → 오른쪽 패널 위쪽에 자동설계 카드(체크박스 3개, ③ 대상 부품 선택, 범위 설정 펼침, [실행]).
- 실행 중: 단계 이름·진행률·남은 시간 추정, [중지]. 점진 계산은 일시 중지된다.
- 완료: 결과 패널을 "현재안 | 최적안" 2열 비교로 바꾼다(2D 분포·길이/폭 프로파일·지표·LED 개수·Milky·형상 값). 3D 뷰는 최적안을 미리 보여 준다(형상 변경·LED 위치). [적용] [취소] [STEP 내보내기(③)].
- 목표를 만족할 수 없을 때: 가장 가까운 안과 이유를 보인다(예: "LED 최대 30개에서도 폭 U 0.62 — 폭 방향 확산 부족, ③ 형상 또는 Milky 상향 권장").

## 5. 검증

## 6. 범위 밖
- LED STEP(고정 위치) 모드의 LED 위치 최적화(PCB 재설계 영역).
- 커버 외 부품(하우징 반사면 각도 등) 형상 최적화.
- 다목적(파레토) 후보 목록 — 이번에는 우선순위 규칙으로 1개안.
- 방향별 휘도(NEE, P5).
