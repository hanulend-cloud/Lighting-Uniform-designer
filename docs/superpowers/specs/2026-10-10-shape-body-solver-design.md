# 형상 몸체(L3·L4) Solver 설계 — STEP 불러오기 + 형상 변화 + 광선추적

- 날짜: 2026-10-10
- 선행: L2 solver(`2026-10-07-l2-diffusion-solver-design.md`) — 소재·응답표·검증 체계를 그대로 재사용
- 대상: 현 L3(축별 두께 프로필 + edgeBoost 스칼라 근사), L4(해석식 `l4BotZAt`) 대체

## 1. 결정 사항 (사용자 확정)
- **L3 = 몸체**: 기구설계 STEP 을 불러온 형상(없으면 L1 두께의 생성 평판) + 형상 변화 ①두께 오프셋 ②두께 프로파일(테이퍼).
- **L4 = 국부 형상**: L3 몸체 위 각 LED 자리의 포켓·돔(기존 L4 파라미터 gap·flat·각도·R·rise 를 국부 형상 정의로 재사용).
- **소재**: L3 단독 = 투명(PC 등, n 입력). L2 를 켜면 같은 몸체 전체가 Milky resin(L2 소재: 추상 Milky / DB HG / DB Mie 그대로).
- **계산**: 2단 solver — 정확한 MC 기준 추적기 + 자동탐색용 빠른 결정론 solver, 최종안은 MC 로 자동 교차검증.

## 2. 근거
- 업계 표준: 형상 광학계(도광·커버 렌즈)는 비순차 광선추적(LightTools·Speos·ASAP·TracePro), Monte Carlo 집계.
- 검증 관행: 광선 수 수렴 점검, 해석해(단순 형상) 대조, ray-splitting 유무 결과 일치.
  (출처: Lambda Research TracePro, 3DOptix, Frontiers AOT 2013 도광판 해석모델 vs ASAP, SPIE 6338)

## 3. 형상 파이프라인
### 3.1 불러오기 (G0, OpenCASCADE.js worker — 기존 STEP 내보내기와 같은 빌드)
- `STEPControl_Reader` → 솔리드(여러 개면 체적 최대 1개 + 경고), 단위 mm.
- **방향**: 출광면 = +Z. 자동 = 법선이 +Z 에 가장 가까운 최대 면적 면 그룹을 윗면으로. 사용자 보정: Z 뒤집기, XY 90° 회전.
- **정렬**: 몸체 외곽(bbox) 중심 = 타겟 중심, 윗면 최고점 z = 깊이(LED→상면). 몸체 외곽이 타겟보다 작으면 경고.
- **2.5D 높이맵 표본화**: 격자(기본 0.2mm, 셀 ≤ 1.5M)에서 수직선-솔리드 교차 → 윗면 z_t(x,y)·바닥면 z_b(x,y)·외곽 마스크.
  교차가 2개를 넘는 셀(언더컷·리브·훅) = 비 2.5D → 비율을 보고, 그 셀은 최외곽 두 교차로 근사 + "근사 적용" 경고.
- 불러온 형상 정보 표시: 외곽 크기, 두께 범위, 윗면 곡률 유무, 비 2.5D 비율.
### 3.2 형상 변화 (G1)
- 해석식으로 바닥 높이맵에 적용: z_b' = z_b − Δ_off − Δ_taper(x,y) + Δ_L4(x,y; LED 위치).
  - Δ_off: 두께 오프셋(mm, +는 두껍게).
  - Δ_taper: 축별 3점(중심·중간·가장자리) **두께 변화량**(절대 두께 아님 — 불러온 형상의 원래 두께 위에 더함), 모서리 R. 생성 평판이면 기존 L3 의미와 같음.
  - Δ_L4: LED 마다 국부 형상(flat 반경, 경사각, R 전이, gap/rise) — 기존 L4 식을 높이맵 함수로 이식.
- 제약 검사: 최소 두께(살두께) ≥ 기존 thicknessBounds 하한, 바닥이 LED 상단(z = sizeZ+0.5)과 간섭 금지 → 위반 시 오류 표시.
- **수정 STEP 내보내기**: 같은 Δ 함수로 커터/추가 솔리드(높이장 B-spline 면 → 프리즘)를 만들어 원본 B-rep 에 Cut/Fuse.
  **V-G**: 내보낸 STEP 을 다시 표본화한 높이맵과 solver 높이맵 차 ≤ 0.05mm.

## 4. Solver
### 4.1 S1 — MC 기준 추적기 (`src/engine/shape/mc-body.js`, Worker)
- 기하: 2.5D 높이맵(윗면·바닥 이중선형 패치, 법선 = 기울기), 외곽 수직 측벽, 캐비티 측벽, PCB 평면(z=0).
- 물리: LED 배광(cos^m / Gaussian), 계면 Fresnel(비편광)·TIR(부분 탈출 가중 + 비종단 분기는 확률 선택),
  몸체 내부 체적 산란(L2 소재 시: HG 또는 Mie 표 샘플러, μs·μa), PCB Lambertian ρ_b, 캐비티 측벽(투명=Fresnel 정반사, 밀키=확산 R_w).
- 출력: 상면 출사도 맵(관찰면 +0.1mm), 출사각 히스토그램(휘도·cone), 에너지 장부(상면·측면·하면·흡수·PCB·누설).
### 4.2 S2 — 빠른 solver (`src/engine/shape/fast-body.js`)
- 투명: LED 별 각도 격자 광선관(ray-tube) — 바닥 굴절 → 상면 도달 사각형의 면적으로 조도 분배(잡음 없음),
  계면 반사·TIR 은 가지(최대 4회, 에너지 1e-3 미만 절단)로 추적, 측벽 정반사.
- 밀키: 바닥 입사 조도(각도 밴드)는 광선관으로, 몸체 응답은 **국소 두께 τ'(x,y)** 의 L2 응답표(국소 슬래브 근사),
  재순환은 L2 캐비티 solver(평균 갭). 두께 변화가 커널 폭(~t) 대비 급하면 근사 저하 경고.
- 휘도: 기존 카메라 경로(굴절 시선 추적)를 높이맵 바닥으로 일반화 + 산란분은 L2 3성분 방식.
### 4.3 S3 — 자동 교차검증
- solveCombo 최종안이 바뀌면 Worker 에서 S1 실행(광선 수: 잡음 1% 목표) → 빠른 solver 와 비교.
- 배지 "MC 교차검증 ✅/❌" — 기준: 중심부 균일도 차 ≤ 2%p, 평균 출사 차 ≤ 3%. 진행 중 "검증 중…".

## 5. 자체검증
| ID | 검사 | 기준 |
|---|---|---|
| VS1 | 평탄 높이맵(일정 두께) → L1 해석(2계면 Fresnel·직접광) | ≤ 1% |
| VS2 | 에너지 장부 합 = 방출 | ≤ 1e-3 (S2 결정론), ≤ 0.5% (S1) |
| VS3 | 단일 광선: 쐐기 편향각·임계각·Fresnel 계수 해석식 | ≤ 1e-9 |
| VS4 | 수렴: S2 각도 격자 2배 / S1 광선 4배 → 결과 변화 | ≤ 1% |
| VS5 | 독립 2D 추적기(Python, 별도 구현) 압출형 프로필 | 출사 프로파일 ≤ 2% |
| VS6 | S1 밀키 평판 vs L2 PSF solver | 중심부 평균 ≤ 3%, min/max ≤ 2%p |
| VS7 | S2 vs S1 (테스트 형상 세트 + 런타임 S3) | 균일도 ≤ 2%p, 평균 ≤ 3% |
| V-G | 수정 STEP 재표본화 vs solver 높이맵 | ≤ 0.05mm |

## 6. UI
- 기구 그룹: [STEP 불러오기] [방향 보정 Z뒤집기·90°] [원본으로] · 불러온 형상 정보 · [수정 STEP 내보내기].
- L3 카드: 두께 오프셋, 두께 변화 프로파일(X·Y 3점), 모서리 R — 생성 평판/불러온 형상 공통. 소재 표시(투명 / L2 Milky).
- L4 카드: 국부 형상 파라미터(기존) — "L3 몸체 위 각 LED 자리" 표기.
- 평면·단면·3D 뷰는 높이맵으로 그림(불러온 형상이 그대로 보이게). 배지: 계산 정합성(VS 계열) · MC 교차검증 · 실물 보정.
