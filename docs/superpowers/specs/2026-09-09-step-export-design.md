# STEP(STP) 3D CAD 내보내기 — 설계 문서

## 배경

Uniform Design Simulator는 L1~L5 조합으로 조명기구의 확산 형상(바디)을 계산하고,
SIDE VIEW / TOP VIEW / 입체뷰로 결과를 보여준다. 지금까지는 화면 표시와 JSON
스펙 저장만 가능했다. 실제 금형·사출 발주를 위해서는 이 형상을 CAD에서 열 수
있는 3D 도면(STEP, .stp)으로 내보낼 수 있어야 한다.

## 범위

- 내보내는 대상: **현재 적용된 조합(최종 구조)** 1건. L1~L5 개별 미리보기는
  범위에서 제외한다.
- 포함 요소:
  - **바디**: L1~L4 조합으로 계산된 확산판/도파관 형상 (L5 돌기 포함, 하단면에
    Boolean 결합)
  - **LED**: `spec.led.sizeX × sizeY × sizeZ` 직육면체 박스, solver가 계산한
    실제 LED 좌표(`combo.leds` 또는 이에 준하는 좌표 목록)마다 배치
  - **PCB**: 타겟 X×Y 크기의 평판, 두께는 스펙에 값이 없으므로 기본값
    **1mm**를 사용
- 단위: mm. 포맷: **STEP AP214** (`STEPControl_Writer`가 기본 지원하는 스키마).
- LED·PCB는 바디와 Boolean 결합하지 않고 같은 STEP 파일 안에 별도 솔리드로
  포함한다(어셈블리 형태).

## 기술 구조

- **OpenCASCADE.js (WASM 빌드)** 를 CDN에서 로드해 실제 CAD 커널 연산(로프트,
  필렛 근사, Boolean, STEP 직렬화)을 수행한다.
- 무거운 연산(특히 L5 돌기 수가 많을 때의 반복 Boolean Fuse)이 메인 UI 스레드를
  멈추지 않도록 **Web Worker** 안에서 OpenCASCADE.js를 실행한다.
  - 메인 → 워커: 현재 조합의 형상 파라미터(geometry.js가 렌더링에 쓰는 것과
    동일한 값), LED 좌표 목록, `spec.led` 치수, PCB 두께.
  - 워커 → 메인: 진행률 메시지(돌기 N/M개 결합 등) + 완료 시 STEP 텍스트,
    실패 시 에러 메시지.
  - 메인 스레드는 받은 STEP 텍스트를 Blob으로 감싸 다운로드를 트리거한다
    (워커 자체는 파일 다운로드를 시작할 수 없음).

## 레벨별 형상 생성 전략

기존 렌더링 코드(`bodyProfile`, `l4RiseAt`, `l4BotZAt` 등, `src/model/levels.js`
· `src/model/geometry.js`)를 그대로 재사용해 **화면 표시와 STEP 형상이 항상
일치**하도록 한다. 새로 물리·형상 공식을 유도하지 않는다.

1. **바디(L1~L4 조합)**: 기존 프로파일 함수로 여러 Z 높이의 단면(사각형/모서리
   라운드 사각형 윤곽)을 촘촘히 샘플링 → OpenCASCADE의 로프트(Loft,
   `BRepOffsetAPI_ThruSections` 상당)로 단면들을 이어붙여 하나의 솔리드를
   만든다. 모서리 R·L4의 각도 필릿 같은 곡선 전이는 촘촘한 샘플링으로
   근사한다(육안·치수상 차이는 무시할 수준).
2. **L5 미세패턴**: 활성화 시, solver가 계산한 LED 피치를 그대로 사용해 각
   격자 위치마다 피라미드/돔/프리즘 돌기 솔리드를 만들고, 바디 하단면에
   `dir`(돌출/오목)에 따라 **Boolean Fuse**(돌출) 또는 **Boolean Cut**(오목)으로
   결합한다. 돌기 수가 많으면 일정 개수(예: 200개) 단위로 배치(batch) Fuse해
   누적 연산 비용을 관리한다.
3. **LED**: `spec.led` 치수의 박스를 solver가 실제로 배치한 좌표마다 생성,
   LED 평면(Z=0 기준)에 배치. 바디와는 결합하지 않는다.
4. **PCB**: 타겟 X×Y 크기의 평판(두께 1mm 기본값)을 LED와 같은 평면에 배치.

## UI/UX 흐름 & 안전장치

1. 사용자가 헤더의 새 **"STEP 내보내기"** 버튼(기존 "JSON 내보내기" 옆) 클릭.
2. L5가 활성화되어 있으면 예상 돌기 개수를 계산한다. **2,000개 초과** 시
   확인 다이얼로그를 띄운다: "돌기 N개 — 계산에 시간이 오래 걸리거나
   브라우저가 느려질 수 있습니다. 계속하시겠습니까?" (계속 / 취소)
3. 진행 중에는 오버레이로 "STEP 생성 중… (N/M 돌기 결합)" 진행률을 표시한다
   (워커가 주기적으로 postMessage로 진행 상황을 보고).
4. 완료되면 `.stp` 파일이 바로 다운로드된다.
5. 실패(형상 자가교차, Boolean 실패 등) 시 에러 메시지를 화면에 표시하고,
   실패 지점(예: "N번째 L5 돌기 결합 실패")을 콘솔에 로그로 남긴다.

## 검증 방법

이 개발 환경에는 상용 CAD가 없으므로, 생성된 STEP을 **OpenCASCADE 자체로
다시 읽어 자동 검증**한다:

- 솔리드 개수가 예상과 일치하는지(바디 1 + LED N개 + PCB 1)
- 바디가 watertight(닫힌 shell)인지
- 부피·바운딩박스가 대략 기대값과 일치하는지(예: 바디 부피가 대략
  target 면적 × 평균 두께 근방인지)

`test/smoke.mjs`에 STEP 익스포트 케이스(L1 단독, L3, L4, L5 소량 패턴 —
브라우저/워커 없이 Node에서 opencascade.js를 직접 호출 가능한 형태로 구성)를
추가한다.

## 향후 고려사항 (이번 범위 밖)

- L1~L5 개별 미리보기 형상의 STEP 내보내기
- 실제 CAD(SolidWorks 등)에서 열어보는 수동 검증 — 이 환경에서는 불가하므로
  사용자가 직접 확인 필요
- 필렛을 촘촘한 샘플링 근사가 아닌 진짜 원호/스플라인 곡면으로 만드는 정밀화
