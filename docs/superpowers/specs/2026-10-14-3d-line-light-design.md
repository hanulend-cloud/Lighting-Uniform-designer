# 3D 기구 모드 설계 — 기구·LED STEP 정의 + 3D MC + 라인 균일도 자동설계

- 날짜: 2026-10-14
- 선행: L2 solver(`2026-10-07-l2-diffusion-solver-design.md`), 형상 몸체 solver(`2026-10-10-shape-body-solver-design.md`)
- 대상 사용자: 광학 비전문가 기구설계자. 광학 수식은 내부에만 두고, 화면에는 Milky 0~10·반사율 % 등 직관 값만 표시.

## 1. 결정 사항 (사용자 확정)
- **모드 2개**
  - **평판 모드 (기본)**: 아무것도 불러오지 않은 초기 상태. 현재 L1~L5 면(area) 설계를 그대로 유지한다.
  - **3D 기구 모드**: 기구 STEP 을 불러오면 전환. 이 문서의 대상.
- **대상 제품**: 관측 영역이 면보다는 **라인(직선·원·자유곡선)** 인 경우가 많다. 단면은 곡면·평면 모두 가능하며, 길이 방향으로 형상이 일정하지 않을 수 있다 → 단면 분리 근사를 쓰지 않고 **3D 형상 그대로** 계산한다.
- **LED 배치**: 직하(관측면과 같은 방향) 또는 측면 발광(side-view). 측면 발광은 라인을 따라 배열하는 경우와 끝단에서 입광하는 경우 모두 대상이다(끝단 입광 도광 로드는 이후 단계).
- **판정**: 길이 방향과 폭 방향 균일도를 **모두** 판정한다.
- **L2 가 메인**: 자동설계 변수는 Milky 레벨, LED 개수·피치(직접 배치일 때), Milky 부품 두께(오프셋), LED→커버 거리이다.
- **L3/L4**: 목업 가능한 형상 아이디어 제안. 별도 spec 으로 다룬다(§9).

## 2. 흐름
1. **기구 STEP 불러오기** → 부품별 소재·면 처리 지정 (§3)
2. **LED 정의** → LED STEP 불러오기 또는 툴에서 직접 배치 (§4)
3. **관측면 지정** → 3D 뷰에서 면 클릭, 라인 자동 인식 (§5)
4. **3D 응답 추적** → LED 후보 위치별 MC (§6)
5. **자동설계** → 응답 겹치기·Milky 재가중, 최종안은 전체 MC 로 재검증 (§6)

## 3. 기구물 정의

### 3.1 불러오기
- 기존 `step-import.js` 를 확장해 **모든 솔리드를 유지**한다(현재는 최대 부피 1개만 유지).
- 부품 목록: 이름(STEP 제품명 있으면 사용, 없으면 "부품 N"), 외곽 크기, 부피. 목록을 클릭하면 3D 뷰에서 강조된다.
- 단위는 mm 이다. 메쉬는 기존 OpenCASCADE 삼각화를 쓰고, 추적용 가속 구조(BVH)를 만든다.

### 3.2 부품 소재 (체적)
| 종류 | 입력 | 광학 모델 |
|---|---|---|
| Milky | DB 소재 + Milky 레벨 0~10 | L2 소재 모델 그대로(추상 Milky / DB HG / DB Mie): 체적 산란 μs·g·μa, 굴절률 n |
| 투명 | 소재(PC/PMMA), 착색 시 투과율 %(기준 두께 표시) | 굴절률 n, 흡수 μa |
| 반투과 백색 | 소재 + 기준 두께에서 투과율 % | 고산란 체적 매질(투과율에 맞춰 μs 결정) |
| 불투명 | — | 내부로 빛이 들어가지 않는다. 표면 동작은 면 처리가 결정한다 |

### 3.3 면 처리 (표면, 면 단위)
| 종류 | 입력 | 단계 |
|---|---|---|
| 광택 (기본) | — | 1 (Fresnel 굴절·반사·전반사) |
| 백색 확산 반사 | R % | 1 (Lambert) |
| 금속 증착·크롬 | R % | 1 (경면) |
| 흑색 | R % | 1 (확산 R + 광택 Fresnel) |
| 시보·텍스처 | MT 등급 → 헤이즈 | 2 (등급별 산란 데이터 필요) |
| 인쇄 차광 패턴 | 패턴 | 3 (L3/L4 연계) |

- 부품 소재를 고르면 면 처리 기본값이 따라온다(예: 백색 PC → 백색 확산 반사 90%, 불투명 흑색 → 흑색 5%). 기본값은 사용자가 면 단위로 덮어쓸 수 있다.
- 지정하지 않은 부품의 기본값은 "불투명 + 백색 확산 반사 85%"이다. Milky 부품만 지정하면 바로 계산할 수 있다.

### 3.4 접촉면 자동 감지
- 서로 다른 부품의 면이 거리 ≤ 0.02mm 이고 법선이 반대 방향으로 겹치면 **광학 접촉**(이중사출·접착)으로 판정한다. 공기층 없이 두 매질의 굴절률로 바로 굴절시킨다.
- 감지 결과는 목록에 표시하고, 사용자가 "공기층 있음"으로 바꿀 수 있다.

## 4. LED 정의

### 4.1 LED STEP (PCB+LED) 불러오기
- **위치 맞춤**: 기구 STEP 과 같은 어셈블리 원점에서 내보냈다고 가정한다. 어긋나면 이동(x,y,z)·회전(축별 각도) 값을 입력한다.
- **LED 인식**: LED 1개를 클릭하면 외곽 크기가 같은(±0.05mm) 솔리드를 모두 LED 로 인식한다. 인식 개수를 표시하고 개별 제외를 허용한다.
- **발광 방향**: 첫 LED 의 발광면을 클릭(직하: 윗면, 측면 발광: 옆면)하면, 나머지 LED 에는 각 솔리드의 자세(주축)에 맞춰 같은 면이 자동 적용된다.
- **PCB**: LED 가 아닌 가장 큰 솔리드를 PCB 로 보고, 솔더레지스트 색(백색 R 80% / 녹색 R 30% / 흑색 R 5%)을 고른다.
- 자동설계에서 LED 위치는 **고정**이다.

### 4.2 툴에서 직접 배치
- PCB 면(기구 부품의 면 클릭) 또는 PCB 높이를 지정한다.
- 관측 라인(§5)을 PCB 면에 투영한 경로를 따라 개수·피치로 배치한다. 직하는 PCB 법선 방향, 측면 발광은 라인 접선 기준 좌/우를 고른다.
- 자동설계에서 개수·피치를 바꿀 수 있다.

### 4.3 LED 사양
- 기존 LED 라이브러리(배광, 광속, 패키지 크기)를 쓴다. 측면 발광 패키지는 배광 기준축이 발광면 법선이다.

## 5. 관측면과 라인 인식
- **지정**: 3D 뷰에서 발광면을 클릭한다(여러 개 가능).
- **관측 방향**: 기본값은 선택한 면들의 면적 가중 평균 법선이다. 직접 입력할 수 있다.
- **라인 인식**
  1. 선택한 면을 관측 방향 평면에 투영해 2D 영역을 만든다.
  2. 중심선(skeleton)을 추출한다. 원·호이면 원으로 맞춘다(잔차 ≤ 0.1mm).
  3. 각 관측점을 **(s: 중심선 따라 거리, w: 중심선에서 폭 방향 거리)** 로 변환한다.
- **휘도 집계 (2026-10-15 개정, P3 실측 반영)**: 관측면을 나가 관측 방향 ±cone 안으로 탈출하는 빛을 (s,w) 격자에 집계한다.
  - 기본 cone = 90°(출사도). Milky 확산면을 지난 빛은 Lambert 에 가까워 휘도 ∝ 출사도(평판 모드 L2 와 같은 가정)이다.
  - 처음 정한 ±10°·0.5mm 격자는 실측에서 잡음 때문에 판정이 불가능했다. 샘플 기구 20만 광자 기준 0.5mm 셀당 광자 약 1개였고, 같은 정밀도를 얻으려면 약 5천만 광자가 필요하다.
  - 방향별 휘도(좁은 원뿔)는 P5 의 관측 방향 다음 사건 추정기(NEE)로 제공한다. cone 은 패널에서 조절할 수 있다.
  - 격자는 자동이다. s 구간 = max(1mm, 길이/100), w 구간 = max(0.5mm, 최대 폭/8). 수동으로 덮어쓸 수 있다.
- **판정**
  - 길이 방향: s 를 따라 (폭 평균 밝기) min/max ≥ 목표.
  - 폭 방향: s 창(기본 max(5mm, 길이/10))마다 폭 방향 밝기 분포를 평균한 뒤 그 min/max 를 구하고, 모든 창 중 최저값 ≥ 목표. 0.5mm 단면별 판정은 잡음에 묻혀서 이 방식으로 바꿨다.
  - 잡음 지표(구간 값의 배치 간 상대 표준오차)를 함께 표시하고, 판정 여유보다 크면 경고한다.
  - 면 가장자리 0.5mm 는 판정에서 제외한다(조정 가능).
  - 목표값은 길이·폭을 각각 입력한다.

## 6. 계산 엔진

### 6.1 3D MC 추적기 (신규, Worker 병렬)
- **기하**: 부품별 삼각형 메쉬 + BVH. 광선-삼각형 교차, 법선은 삼각형 법선이다(평활 법선은 쓰지 않는다 — 면 경계 오차 방지).
- **물리**
  - 체적: Milky·반투과 백색은 L2 와 같은 산란·흡수 모델과 위상함수를 쓴다.
  - 경계: 매질 경계에서 Fresnel 굴절·반사·전반사를 처리하고, 접촉면에서는 두 매질 사이 굴절을 처리한다.
  - 면 처리: 반사형 면은 §3.3 모델을 따른다.
- **광원**: LED 라이브러리 배광으로 샘플링한다. 발광면은 패키지 크기의 사각 면이다.
- **난수**: L2 에서 검증한 sfc32 + splitmix32 시드를 쓴다.
- **엔진 분리**: 추적 커널은 순수 함수 모듈로 둔다(나중에 WebGPU 이식 가능하게).

### 6.2 응답 재사용 (자동설계 가속)
| 설계 변수 | 방법 | 근사 |
|---|---|---|
| LED 개수·피치 (직접 배치) | 경로를 따라 1mm 간격의 후보 위치마다 LED 1개의 (s,w) 응답을 추적해 두고, 배치에 해당하는 후보 응답을 더한다(피치가 후보 간격의 배수가 아니면 인접 후보를 선형 보간) | 선형 중첩 — 근사 없음(보간 제외) |
| LED STEP 고정 배치 | LED 별 응답 1회 | 없음 |
| Milky 레벨 | 광선마다 Milky 매질 안 경로 길이 L 과 산란 횟수 k 를 기록하고, 다른 Milky(μs → μs')에서는 가중치 (μs'/μs)^k · exp(−(μs'−μs)·L) 를 곱한다(perturbation MC). Milky 레벨 = 입자 농도라서 위상함수는 그대로다 | 비율이 크면 분산이 커진다 → 기준 Milky 2~3개로 구간을 나누고, 가중치 분산이 한도를 넘으면 그 구간을 다시 추적한다 |
| Milky 부품 두께, LED→커버 거리 | 형상이 바뀌므로 다시 추적한다. 각 3~5개 이산값 | 이산 탐색 |

- **두께 오프셋**: Milky 부품의 관측면 반대쪽 면을 법선 방향으로 이동한다(메쉬 정점 이동, 자기교차 검사).
- **거리 변경**: LED+PCB 전체를 관측 방향으로 이동한다(기구 간섭 검사).

### 6.3 자동설계 순서 (L2 메인 시나리오)
1. 최대 Milky(투과율 하한 `tMin` 이내)에서 균일도를 만족하는 최소 LED 수(직접 배치) 또는 만족 여부(고정 배치)를 구한다.
2. 그 배치에서 목표를 만족하는 **최소 Milky** 를 이분탐색한다(재가중 사용) → 휘도 최대.
3. 만족하지 못하면 두께 → 거리 순으로 이산값을 탐색한다.
4. 최종안을 전체 MC(재가중·보간 없이)로 재평가해 판정하고, 수치를 확정한다.
5. 만족하지 못하면 가장 가까운 안과 함께 원인(길이 방향 / 폭 방향, 어느 s 구간인지)을 표시한다.

## 9. 범위 밖 (이후 별도 spec)
- 시보·텍스처 산란 데이터(MT 등급별), 인쇄 차광 패턴.
- 끝단 입광 도광 로드(길이 방향 감쇠, 추출 패턴).
- L3/L4 형상 아이디어 제안(국부 두께, 반사벽 각도, 리브 등 목업 가능한 변경 + 예상 개선폭).
- WebGPU 가속.
- 색(분광) 계산. 1단계는 단색 광속 기준이다.
