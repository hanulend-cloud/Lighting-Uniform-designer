# 3D 기구 모드 CAD식 UI — 점진 계산 · 결과 그래프 · 설계 점검 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 3D 기구 모드를 CAD식 화면(명령 막대 · 피처 트리/속성 · 3D 뷰 · 결과 그래프 · 상태 띠)으로 바꾸고, 값이 바뀌면 자동으로 점진 계산해 균일도·광량·설계 점검을 항상 보여 준다.

**Architecture:** 순수 모듈을 먼저 만들고 Node 테스트로 검증한다.

| 모듈 | 내용 |
|---|---|

| `src/engine/mech3d/chunk-host.js` | Worker 장면 캐시·청크 처리(순수 — Worker 와 Node 시험이 같이 씀) |

그다음 UI 를 만든다. `mech3d-view.js` 를 확장하고(보기 4종·축·색지도·점검 표식·단면), 기존 편집기를 노드별로 나눈 뒤, 명령 막대·피처 트리·속성·결과·상태 띠를 `src/ui/m3/app.js` 로 묶는다. `main.js` 에는 mount/unmount 만 남긴다.

## spec 대비 결정 (모호한 부분 해소)

1. **관측면 색지도는 세분 덧그림 메쉬로 그린다.** STEP 평면은 보통 삼각형 2개라서 정점 색만으로는 분포가 보이지 않는다. 그래서 관측면 삼각형을 집계 칸 크기(min(ds, cell))까지 나눈 덧그림 메쉬(최대 20만 삼각형)를 관측 방향으로 0.05mm 띄워 그린다. 각 정점의 (s,w) 집계 칸 값으로 색을 칠한다(spec §2 의 "정점 → (s,w) → 셀 값" 그대로). 칸이 무효면 같은 s 행의 가장 가까운 유효 칸 값을 쓴다.
2. **휘도 식을 원뿔에 맞게 일반화한다.** Lambert 면에서 ±θ 원뿔이 받는 광속은 `π·L·A·sin²θ` 다. 그래서 `L = Φ/(A·π·sin²θ)` 로 쓴다. 기본 cone 90° 에서는 spec 식과 같다.
3. **새는 빛 분류:** 관측면에서 나갔지만 원뿔 밖으로 간 빛은 새는 빛이 아니다. 표시 대상(가장 큰 면)에서 `'-1|-1'` 은 3D 면이 없으므로 표식을 그리지 않고, 상태 띠 수치에만 넣는다.
4. **배치 정규화:** Worker 수가 10 의 약수가 아니면 배치마다 청크 수가 다르다. 그래서 배치 누적을 청크 수로 나눈 평균을 통계에 넣는다. 청크가 1개인 배치는 그대로 넘기므로(÷1 없음) 일괄 계산과 비트 단위로 같다.
5. **도달률(점검 ②):** 지향각 반각(최대 89°) 원뿔 안 64방향(피보나치 나선, cos 균등)으로 쏜다. 투과 부품은 통과하고, 관측면 부품에 닿으면 도달로 센다. 불투명 부품에 막히거나 빈 공간으로 빠지면 미도달이다. 거리는 LED 축 광선이 관측면 부품에 닿는 거리다(막히면 없음).
6. **간섭(점검 ①) 개수는 건수다.** 발광점 안쪽 판정(+0.05mm 축 방향으로 띄워 홀짝)과 몸체 상자 겹침(0.02mm 줄여 맞닿음 제외)을 각각 1건으로 센다.
7. **살두께(점검 ③):** 투과 부품의 면적 상위 400개 삼각형 중심에서 −법선으로 쏜다. 맞은편 면이 마주 볼 때(법선 내적 < −0.5)만 두께로 본다. 모서리·경사면 오탐을 줄이기 위해서다.
8. **단면:** spec 에 방식이 없다. 그래서 X/Y/Z 축에 수직인 평면 1개와 위치 슬라이더로 한다(평면의 + 쪽을 잘라 냄).
9. **새 저장 필드:** `light.spec.fluxLm`(기본 0 = 상대값), `observe.targetLum`(null), `observe.targetNoise`(0.02), `mspec.checks = { minWall: 0.8, minReach: 0.5, maxLeak: 0.2 }`. `migrateMech3d` 가 채운다.
10. **계산 진행은 store 알림을 거치지 않는다.** 결과는 `store.session.calc` 에 두지만, 1초마다의 갱신은 app 이 결과 패널·상태 띠·색지도만 직접 다시 그린다. 속성 입력칸이 매초 다시 그려지면 입력 중 포커스를 잃기 때문이다.
11. **spec 표에 없는 파일을 더한다.** `pool.js`(Worker 풀, main.js 에서 옮김), `leds.js`(LED 인식 도우미, main.js 에서 옮김), `chunk-host.js`(Worker 청크 처리 순수부). `importMech3d` 는 `spec` 을 바꾸므로 main.js 에 남긴다.
12. **빠른/정밀 계산 버튼과 Worker `run` 메시지를 없앤다.** 자동 점진 계산으로 대체한다. `runJob` 은 동등성 시험 기준으로 남긴다.
13. **평면 보기의 카메라:** 방향을 `[0, −1e-3, 1]` 로 하고 up 은 z 로 둔다. OrbitControls 는 생성 시 up 으로 회전축을 정하므로 up 을 바꾸지 않는다.
14. **성능 기준(spec §6)은 계산 시작 시점부터 잰다.** 디바운스 0.5초가 끝나고 '장면 준비'에 들어간 때가 기준이다(첫 지표 ≤ 2초, 잡음 ±5% ≤ 10초).

  return combineSources(emitters.map((e) => ledSource({ x: e.pos[0], y: e.pos[1], z: e.pos[2], axis: e.axis, xAxis: e.xAxis, model: ledSpec.model, beam: ledSpec.beam, sizeX: ledSpec.sizeX, sizeY: ledSpec.sizeY })));

// 점진 계산 청크 — spec 2026-10-15 m3-cad-ui §4. runMC3D 1회(배치 하나)를 seed 그대로 돌린다.
// runJob 배치 b 와 같은 시드(seed·7919+b)·광자 수를 주면 acc·cnt·ledger 가 비트 단위로 같다(같은 콜백 순서).
// leak: 관측면이 아닌 면으로 탈출한 빛 — 탈출 광자의 마지막 출사 (부품, 면) 별 가중치 합. 출사 기록이 없으면(투과 부품을 거치지 않고 틈으로 바로) '-1|-1'.
// escObs: 마지막 출사가 관측면인 탈출 가중치(방향 무관). Σleak + escObs = ledger.escaped.
export function runChunk({ S, line, obs, G, emitters, ledSpec, N, seed }) {
  const src = ledSources(emitters, ledSpec), a = makeAccumulator(G, line, obs);
  const faces = new Set(obs.faces.map((f) => `${f.part}|${f.face}`)), leak = {};
  let lastPart = -1, lastFace = -1, lastP = -1, escObs = 0;
  const r = runMC3D(S, {
    source: src, N, seed,
    onExit(part, face, x, y, z, dx, dy, dz, w, p) { a.onExit(part, face, x, y, z, dx, dy, dz, w, p); lastPart = part; lastFace = face; lastP = p; },
    onEscape(x, y, z, dx, dy, dz, w, p) {
      a.onEscape(x, y, z, dx, dy, dz, w, p);
      const k = lastP === p ? `${lastPart}|${lastFace}` : '-1|-1';
      if (faces.has(k)) escObs += w; else leak[k] = (leak[k] ?? 0) + w;
    },
  });
  return { acc: a.acc, cnt: a.cnt, ledger: r.ledger, leak, escObs, ms: r.ms };
}

export function makeChunkHost({ getTable, getDb = () => null }) {
  let cache = null;
  return {
    get sceneKey() { return cache?.sceneKey ?? null; },
    // 반환 { reply, transfer } — 처리할 메시지가 아니면 null

      }
      if (m.type === 'chunk') {
        if (!cache || cache.sceneKey !== m.sceneKey) return { reply: { sceneKey: m.sceneKey, stale: true }, transfer: [] };
        const { S, line, obs, G, emitters, ledSpec } = cache;
        const r = runChunk({ S, line, obs, G, emitters, ledSpec, N: m.N, seed: m.seed });
        return { reply: { sceneKey: m.sceneKey, acc: r.acc, cnt: r.cnt, ledger: r.ledger, leak: r.leak, escObs: r.escObs, ms: r.ms }, transfer: [r.acc.buffer, r.cnt.buffer] };

// 가짜 타이머(setTimeout/setInterval) + 비동기 정착 — store·progressive 시험용
export const settle = async (n = 30) => { for (let i = 0; i < n; i++) await new Promise((r) => setImmediate(r)); };
export function fakeTimers() {
  let now = 0, seq = 0;
  const q = new Map(), add = (f, ms, every) => { q.set(++seq, { at: now + ms, f, every }); return seq; };
  return {
    setTimeout: (f, ms) => add(f, ms, 0), clearTimeout: (i) => { q.delete(i); },
    setInterval: (f, ms) => add(f, ms, ms), clearInterval: (i) => { q.delete(i); },
    now: () => now,
    // ms 만큼 시간을 보내며 만기 타이머를 시간 순서로 실행(실행마다 비동기 정착)
    async advance(ms) {
      const end = now + ms;
      await settle();
      for (;;) {
        let id = null, t = null;
        for (const [i, x] of q) if (x.at <= end && (!t || x.at < t.at)) { id = i; t = x; }
        if (!t) break;
        now = t.at;
        if (t.every) t.at += t.every; else q.delete(id);
        t.f();
        await settle();
      }
      now = end;
    },
  };
}

  const subs = new Set();

  const store = {
    mspec, session: initialSession(),
    update(tag, fn) {
      if (!TAGS.includes(tag)) throw new Error(`알 수 없는 변경 태그: ${tag}`);

        t = timers.setTimeout(() => { t = null; persist(); }, delay);
      }
      for (const f of [...subs]) f(tag);
    },
    subscribe(f) { subs.add(f); return () => subs.delete(f); },
    flush() { if (t != null) { timers.clearTimeout(t); t = null; persist(); } },
    dispose() { store.flush(); subs.clear(); },

// 청크 c 의 시드 = seedBase·7919 + c (runJob 배치 시드 규약) → 배치 c % bins 에 모은다. 판정 통계는 배치별 (누적 ÷ 청크 수).

export function photometry(G, sum, ledger, { fluxLm = 0, nLeds = 0, cone = 90 } = {}) {
  let tot = 0, area = 0;
  for (let k = 0; k < sum.length; k++) { tot += sum[k]; area += G.area[k]; }
  const eff = ledger.emitted > 0 ? tot / ledger.emitted : NaN;
  const s2 = Math.sin((Math.min(90, cone) * Math.PI) / 180) ** 2;
  const lum = fluxLm > 0 && nLeds > 0 && area > 0 && Number.isFinite(eff) ? (fluxLm * nLeds * eff) / (area * 1e-6 * Math.PI * s2) : null;
  return { eff, lum, area };
}

    try { await Promise.all(ports.map((p) => p.send({ type: 'scene', sceneKey: j.sceneKey, ...j.scene }))); } catch (e) { fail(g, e); return; }
    if (g !== gen) return;
    state = 'running'; startTick(); emit();
    pumpAll(g);
  }
  function fail(g, e) { if (g !== gen) return; stopTick(); state = 'error'; error = String(e?.message ?? e); emit(); }
  function pumpAll(g) { ports.forEach((_, k) => { if (busy[k] !== g) pump(k, g); }); }
  // 포트 하나에 청크를 하나씩 보낸다(응답이 오면 다음)
  async function pump(k, g) {
    busy[k] = g;
    try {
      while (g === gen && state === 'running' && nextChunk * o.chunkN < o.maxPhotons) {
        const c = nextChunk++;
        let r;
        try { r = await ports[k].send({ type: 'chunk', sceneKey: job.sceneKey, seed: chunkSeed(o.seedBase, c), N: o.chunkN }); } catch (e) { fail(g, e); return; }
        if (g !== gen) return;   // 그사이 다시 시작·취소됨 — 버림
        if (r.stale || r.sceneKey !== job.sceneKey) {
          if (++ignored > o.maxIgnored) { fail(g, new Error('Worker 장면이 맞지 않음 — 다시 계산하세요')); return; }
          continue;
        }
        accumulate(c, r);
        if (state !== 'running') { snap = compute(); emit(); }                              // 일시정지·완료 뒤 도착한 청크
        else if (photons >= o.maxPhotons) finish('max');
        else if (!early && bins.filter(Boolean).length >= 2) { early = true; onTick(); }   // 첫 지표는 1초를 기다리지 않음
      }
    } finally { if (busy[k] === g) busy[k] = 0; }
  }
  function accumulate(c, r) {
    const b = c % o.bins, n = r.acc.length;
    const B = bins[b] ?? (bins[b] = { acc: new Float64Array(n), cnt: new Float64Array(n), n: 0 });
    for (let k = 0; k < n; k++) { B.acc[k] += r.acc[k]; B.cnt[k] += r.cnt[k]; }
    B.n++;
    for (const key in ledger) ledger[key] += r.ledger[key] ?? 0;
    for (const key in r.leak ?? {}) leak[key] = (leak[key] ?? 0) + r.leak[key];
    photons += o.chunkN; doneChunks++;
  }
  function compute() {
    const filled = bins.filter(Boolean);
    if (!job || filled.length < 2) return { stats: null, sum: null, photometry: null };
    const accs = filled.map((B) => (B.n === 1 ? B.acc : B.acc.map((v) => v / B.n)));   // 청크 1개면 그대로(비트 일치)
    const cnts = filled.map((B) => (B.n === 1 ? B.cnt : B.cnt.map((v) => v / B.n)));
    const stats = tallyStats(job.G, accs, job.obs, cnts);
    const sum = new Float64Array(job.G.ns * job.G.nw);
    for (const B of filled) for (let k = 0; k < sum.length; k++) sum[k] += B.acc[k];
    return { stats, sum, photometry: photometry(job.G, sum, ledger, { fluxLm: job.fluxLm ?? 0, nLeds: job.nLeds ?? 0, cone: job.obs.cone ?? 90 }) };
  }
  function onTick() {
    if (!job) return;
    snap = compute();
    const rn = snap.stats?.relNoise;
    if (state === 'running' && doneChunks >= o.bins && rn != null && rn <= o.targetNoise) { finish('converged'); return; }
    emit();
  }
  function finish(r) { state = 'done'; reason = r; stopTick(); snap = compute(); emit(); }

  function pause() { if (state !== 'running') return; state = 'paused'; stopTick(); emit(); }
  function resume() { if (state !== 'paused') return; state = 'running'; startTick(); emit(); pumpAll(gen); }
  // 목표만 바뀜 — 누적 데이터로 판정만 다시. 잡음 목표를 현재 잡음보다 낮추면(수렴 멈춤 상태) 계산 재개
  function setJudge({ obs = null, targetNoise = null, fluxLm = null } = {}) {
    if (targetNoise != null) o.targetNoise = targetNoise;
    if (job) {
      job = { ...job, obs: obs ? { ...job.obs, targetLen: obs.targetLen, targetWid: obs.targetWid } : job.obs, fluxLm: fluxLm ?? job.fluxLm };
      snap = compute();
      const rn = snap.stats?.relNoise;
      if (state === 'done' && reason === 'converged' && rn != null && rn > o.targetNoise && photons < o.maxPhotons) {
        state = 'running'; reason = null; startTick(); emit(); pumpAll(gen); return;
      }
    }
    emit();
  }
  function cancel() {
    gen++; stopTick();
    if (debounce != null) { timers.clearTimeout(debounce); debounce = null; }
    job = null; pendingJob = null; resetAcc(); state = 'idle'; reason = null; error = null;
    emit();
  }
  function snapshot() {
    return {
      state, reason, error, photons, chunks: doneChunks, ignored, sceneKey: job?.sceneKey ?? null,
      stats: snap?.stats ?? null, sum: snap?.sum ?? null, photometry: snap?.photometry ?? null,
      ledger: { ...ledger }, leak: { ...leak }, bins: bins.map((b) => b && { acc: b.acc, n: b.n }),
      G: job?.G ?? null, obs: job?.obs ?? null, targetNoise: o.targetNoise,
    };
  }
  return { restart, pause, resume, cancel, setJudge, snapshot };
}

// 설계 점검 4종 — spec 2026-10-15 m3-cad-ui §5. 순수 함수(Node 시험). 상태: 'ok' | 'warn' | 'bad' | 'na'(대상 없음).
// rt = 런타임 장면(getMech3d(): parts[{positions,triangles,faceIds,bvh}], combined{partOf}, bvh), mspec = spec.mech3d.
// 기하 점검(①②③)은 값이 바뀌면 바로, 새는 빛(④)은 점진 계산 결과(runChunk 의 leak)로 한다.
import { intersectRay, queryBox } from './bvh.js';
import { defaultChecks } from './defs.js';

const PARITY_DIR = [0.48, 0.6, 0.64];   // 단위 벡터, 축·대각과 어긋나게(모서리 스침 줄임)
const sub = (a, b) => [a[0] - b[0], a[1] - b[1], a[2] - b[2]];
const dot = (a, b) => a[0] * b[0] + a[1] * b[1] + a[2] * b[2];
const cross = (a, b) => [a[1] * b[2] - a[2] * b[1], a[2] * b[0] - a[0] * b[2], a[0] * b[1] - a[1] * b[0]];
const isTrans = (mspec, q) => (mspec.parts[q]?.material?.kind ?? 'opaque') !== 'opaque';
const vtx = (P, i) => [P[3 * i], P[3 * i + 1], P[3 * i + 2]];
function triInfo(P, T, t) {
  const a = vtx(P, T[3 * t]), b = vtx(P, T[3 * t + 1]), c = vtx(P, T[3 * t + 2]), n = cross(sub(b, a), sub(c, a)), l = Math.hypot(...n) || 1;
  return { n: n.map((v) => v / l), area: l / 2, c: [(a[0] + b[0] + c[0]) / 3, (a[1] + b[1] + c[1]) / 3, (a[2] + b[2] + c[2]) / 3] };
}

// 점 p 가 닫힌 메쉬(부품) 안인가 — 반직선 교차 수의 홀짝
export function insidePart(part, p) {
  const [dx, dy, dz] = PARITY_DIR;
  let t0 = 1e-6, skip = -1, n = 0;
  for (let k = 0; k < 1000; k++) {
    const h = intersectRay(part.bvh, p[0], p[1], p[2], dx, dy, dz, t0, Infinity, skip);
    if (!h) break;
    n++; t0 = h.t + 1e-7; skip = h.tri;
  }
  return (n & 1) === 1;
}

// 삼각형–축정렬 상자 겹침(분리축 13개) — c: 상자 중심, h: 반 크기
export function triBoxOverlap(c, h, a, b, d) {
  const v0 = sub(a, c), v1 = sub(b, c), v2 = sub(d, c), e0 = sub(v1, v0), e1 = sub(v2, v1), e2 = sub(v0, v2);
  const sep = (ax) => {
    const p0 = dot(v0, ax), p1 = dot(v1, ax), p2 = dot(v2, ax), r = h[0] * Math.abs(ax[0]) + h[1] * Math.abs(ax[1]) + h[2] * Math.abs(ax[2]);
    return Math.min(p0, p1, p2) > r || Math.max(p0, p1, p2) < -r;
  };
  for (const e of [e0, e1, e2]) if (sep([0, -e[2], e[1]]) || sep([e[2], 0, -e[0]]) || sep([-e[1], e[0], 0])) return false;
  for (let k = 0; k < 3; k++) if (Math.min(v0[k], v1[k], v2[k]) > h[k] || Math.max(v0[k], v1[k], v2[k]) < -h[k]) return false;
  return !sep(cross(e0, e1));
}

// ① LED–부품 간섭: 발광점(축 방향 lift 띄움)이 부품 안 / LED 몸체 외곽 상자(tol 만큼 줄임)가 부품 삼각형과 겹침 — 각각 1건
// emitters: [{pos, axis}], bodies: [{led, lo:[3], hi:[3]}](LED STEP 의 LED 몸체 외곽, 월드 좌표)
export function checkInterference({ rt, emitters = [], bodies = [], tol = 0.02, lift = 0.05 }) {
  if (!emitters.length && !bodies.length) return { status: 'na', count: 0, items: [] };
  const items = [], cand = [];
  emitters.forEach((e, i) => {
    const al = Math.hypot(...e.axis) || 1, q = e.pos.map((v, k) => v + (lift * e.axis[k]) / al);
    rt.parts.forEach((part, p) => { if (insidePart(part, q)) items.push({ led: i, part: p, kind: 'inside', pos: e.pos }); });
  });
  for (const b of bodies) {
    const lo = b.lo.map((v) => v + tol), hi = b.hi.map((v) => v - tol);
    if (lo.some((v, k) => v > hi[k])) continue;
    const c = lo.map((v, k) => (v + hi[k]) / 2), h = lo.map((v, k) => (hi[k] - v) / 2);
    rt.parts.forEach((part, p) => {
      const P = part.positions, T = part.triangles;
      for (const t of queryBox(part.bvh, lo, hi, cand)) {
        if (triBoxOverlap(c, h, vtx(P, T[3 * t]), vtx(P, T[3 * t + 1]), vtx(P, T[3 * t + 2]))) { items.push({ led: b.led, part: p, kind: 'overlap', pos: c }); break; }
      }
    });
  }
  return { status: items.length ? 'bad' : 'ok', count: items.length, items };
}

// 축 axis 둘레 반각 halfDeg 원뿔 안 n 방향(cos 균등 + 황금각 나선, 결정적)
export function coneDirs(axis, halfDeg, n) {
  const al = Math.hypot(...axis), a = axis.map((v) => v / al), t = Math.abs(a[2]) < 0.9 ? [0, 0, 1] : [1, 0, 0];
  let u = cross(a, t); const ul = Math.hypot(...u); u = u.map((v) => v / ul);
  const v = cross(a, u), c0 = Math.cos((halfDeg * Math.PI) / 180), ga = Math.PI * (3 - Math.sqrt(5)), out = [];
  for (let k = 0; k < n; k++) {
    const ct = 1 - ((1 - c0) * (k + 0.5)) / n, st = Math.sqrt(Math.max(0, 1 - ct * ct)), ph = k * ga;
    const d = [0, 1, 2].map((i) => st * Math.cos(ph) * u[i] + st * Math.sin(ph) * v[i] + ct * a[i]), l = Math.hypot(...d);
    out.push(d.map((x) => x / l));
  }
  return out;
}
// 광선을 따라가며 투과 부품은 통과, 관측 부품에 닿으면 'obs', 불투명 부품이면 'block', 빠져나가면 'miss'
function traceToObs(rt, mspec, obsParts, o, d) {
  let t0 = 1e-6, skip = -1;
  for (let k = 0; k < 64; k++) {
    const h = intersectRay(rt.bvh, o[0], o[1], o[2], d[0], d[1], d[2], t0, Infinity, skip);
    if (!h) return { hit: 'miss' };
    const q = rt.combined.partOf[h.tri];
    if (obsParts.has(q)) return { hit: 'obs', t: h.t };
    if (!isTrans(mspec, q)) return { hit: 'block', part: q, t: h.t };
    t0 = h.t + 1e-7; skip = h.tri;
  }
  return { hit: 'miss' };
}
// ② LED–커버 거리·도달: LED 마다 지향각 안 nRays 광선 중 관측 부품에 닿는 비율, 축 광선의 관측 부품까지 거리
export function checkReach({ rt, mspec, emitters = [], obsParts, beam = 120, nRays = 64, minReach = defaultChecks().minReach }) {
  if (!emitters.length || !obsParts?.size) return { status: 'na', minReach: null, minDist: null, items: [] };
  const half = Math.min(89, beam / 2);
  const items = emitters.map((e, i) => {
    let n = 0; const blk = new Map();
    for (const d of coneDirs(e.axis, half, nRays)) {
      const r = traceToObs(rt, mspec, obsParts, e.pos, d);
      if (r.hit === 'obs') n++; else if (r.hit === 'block') blk.set(r.part, (blk.get(r.part) ?? 0) + 1);
    }
    const al = Math.hypot(...e.axis), ax = e.axis.map((v) => v / al), a = traceToObs(rt, mspec, obsParts, e.pos, ax);
    const blocker = blk.size ? [...blk].sort((x, y) => y[1] - x[1])[0][0] : null;
    return { led: i, pos: e.pos, axis: ax, reach: n / nRays, dist: a.hit === 'obs' ? a.t : null, blocker };
  });
  const mr = Math.min(...items.map((x) => x.reach)), ds = items.map((x) => x.dist).filter((x) => x != null);
  return { status: mr < minReach ? 'warn' : 'ok', minReach: mr, minDist: ds.length ? Math.min(...ds) : null, items };
}

// ③ 살두께: 투과 부품의 면적 상위 samples 개 삼각형 중심에서 −법선 광선 → 마주 보는(법선 내적 < −0.5) 같은 부품 면까지 거리의 최솟값
export function checkThinWall({ rt, mspec, minWall = defaultChecks().minWall, samples = 400 }) {
  let best = null; const items = [];
  rt.parts.forEach((part, p) => {
    if (!isTrans(mspec, p)) return;
    const P = part.positions, T = part.triangles, nT = T.length / 3, order = [];
    for (let t = 0; t < nT; t++) order.push([t, triInfo(P, T, t).area]);
    order.sort((x, y) => y[1] - x[1]);
    let mn = Infinity, at = null;
    for (const [t] of order.slice(0, samples)) {
      const { n, c } = triInfo(P, T, t), o = [c[0] - 1e-5 * n[0], c[1] - 1e-5 * n[1], c[2] - 1e-5 * n[2]];
      const h = intersectRay(part.bvh, o[0], o[1], o[2], -n[0], -n[1], -n[2], 1e-6, Infinity, t);
      if (!h || dot(triInfo(P, T, h.tri).n, n) > -0.5) continue;   // 마주 보지 않는 면(모서리·경사) — 두께로 보지 않음
      const th = h.t + 1e-5;
      if (th < mn) { mn = th; at = c; }
    }
    if (at) { items.push({ part: p, min: mn, pos: at }); if (!best || mn < best.min) best = { part: p, min: mn, pos: at }; }
  });
  if (!best) return { status: 'na', min: null, part: null, pos: null, items };
  return { status: best.min < minWall ? 'warn' : 'ok', ...best, items };
}

// ④ 새는 빛: 청크 결과({ leak, ledger }) 합산
export function mergeLeak(chunks) {
  const leak = {}; let escaped = 0;
  for (const c of chunks) { escaped += c.ledger.escaped; for (const k in c.leak) leak[k] = (leak[k] ?? 0) + c.leak[k]; }
  return { leak, escaped };
}
export function checkLeak({ leak, escaped, maxLeak = defaultChecks().maxLeak }) {
  if (!(escaped > 0)) return { status: 'na', ratio: null, worst: null };
  let tot = 0, wk = null, wv = 0;
  for (const k in leak) { tot += leak[k]; if (leak[k] > wv) { wv = leak[k]; wk = k; } }
  const [part, face] = wk ? wk.split('|').map(Number) : [null, null];
  return { status: tot / escaped > maxLeak ? 'warn' : 'ok', ratio: tot / escaped, worst: wk ? { part, face, ratio: wv / escaped } : null };
}

// 기하 점검 ①②③ 묶음 — 기준값은 mspec.checks(없으면 기본)
export function runGeomChecks({ rt, mspec, emitters = [], bodies = [], obsParts = new Set(), beam = 120 }) {
  const C = { ...defaultChecks(), ...(mspec.checks ?? {}) };
  return {
    interference: checkInterference({ rt, emitters, bodies }),
    reach: checkReach({ rt, mspec, emitters, obsParts, beam, minReach: C.minReach }),
    wall: checkThinWall({ rt, mspec, minWall: C.minWall }),
  };
}

// 관측면 색지도 — spec 2026-10-15 m3-cad-ui §2: 관측면 메쉬 정점 → (s,w) → 집계 지도 칸 값 → 색. 순수 함수(Node 시험).
// STEP 관측면은 삼각형이 커서(평면 = 2개) 정점 색으로는 분포가 안 보인다 → 집계 칸 크기까지 세분한 덧그림 메쉬를 만든다.
const STOPS = [[0x20, 0x30, 0x6e], [0x2a, 0x7b, 0xd5], [0x3f, 0xc1, 0x7a], [0xf2, 0xd3, 0x3c], [0xe0, 0x53, 0x2a]];
export const NO_DATA = [0.42, 0.45, 0.5];
// t(0~1) → [r,g,b](0~1) — 시안(m3-ui-mockup) 색 막대
export function ramp(t) {
  t = Math.max(0, Math.min(0.9999, t)) * 4;
  const i = Math.floor(t), f = t - i, a = STOPS[i], b = STOPS[i + 1];
  return [0, 1, 2].map((k) => (a[k] + f * (b[k] - a[k])) / 255);
}
// 부품 메쉬에서 면 번호 집합의 삼각형만(정점 번호 다시 매김)
export function extractFaces(mesh, faceSet) {
  const P = mesh.positions, T = mesh.triangles, F = mesh.faceIds, remap = new Map(), pos = [], tri = [];
  for (let t = 0; t < F.length; t++) {
    if (!faceSet.has(F[t])) continue;
    for (let j = 0; j < 3; j++) {
      const v = T[3 * t + j];
      let k = remap.get(v);
      if (k === undefined) { k = pos.length / 3; remap.set(v, k); pos.push(P[3 * v], P[3 * v + 1], P[3 * v + 2]); }
      tri.push(k);
    }
  }
  return { positions: Float32Array.from(pos), triangles: Uint32Array.from(tri) };
}
// 삼각형마다 n×n 균등 세분(n = ⌈최대 변/maxEdge⌉). 합계가 maxTris 를 넘으면 maxEdge 를 1.25배씩 키운다. 감김 방향은 원래와 같다.
export function subdivide(m, maxEdge, maxTris = 200000) {
  const P = m.positions, T = m.triangles, nT = T.length / 3, Lmax = new Float64Array(nT);
  const d = (a, b) => Math.hypot(P[3 * a] - P[3 * b], P[3 * a + 1] - P[3 * b + 1], P[3 * a + 2] - P[3 * b + 2]);
  for (let t = 0; t < nT; t++) { const a = T[3 * t], b = T[3 * t + 1], c = T[3 * t + 2]; Lmax[t] = Math.max(d(a, b), d(b, c), d(c, a)); }
  let e = maxEdge;
  const nOf = (t) => Math.max(1, Math.ceil(Lmax[t] / e - 1e-9));
  for (;;) { let tot = 0; for (let t = 0; t < nT; t++) tot += nOf(t) ** 2; if (tot <= maxTris || e > 1e9) break; e *= 1.25; }
  const pos = [], tri = [];
  for (let t = 0; t < nT; t++) {
    const n = nOf(t), A = 3 * T[3 * t], B = 3 * T[3 * t + 1], C = 3 * T[3 * t + 2], base = pos.length / 3;
    const id = (i, j) => base + (i * (2 * n + 3 - i)) / 2 + j;   // 행 i(0..n) 에 정점 n−i+1 개
    for (let i = 0; i <= n; i++) for (let j = 0; j <= n - i; j++) {
      const u = i / n, v = j / n;
      for (let k = 0; k < 3; k++) pos.push(P[A + k] + u * (P[B + k] - P[A + k]) + v * (P[C + k] - P[A + k]));
    }
    for (let i = 0; i < n; i++) for (let j = 0; j < n - i; j++) {
      tri.push(id(i, j), id(i + 1, j), id(i, j + 1));
      if (j < n - i - 1) tri.push(id(i + 1, j), id(i + 1, j + 1), id(i, j + 1));
    }
  }
  return { positions: Float32Array.from(pos), triangles: Uint32Array.from(tri) };
}
// (s,w) → 집계 칸 번호(tally.js makeAccumulator 와 같은 규칙) 또는 −1
export function cellIndex(G, s, w) {
  let i = Math.floor(s / G.ds);
  if (G.closed) i = ((i % G.ns) + G.ns) % G.ns; else if (i < 0 || i >= G.ns) return -1;
  const j = Math.floor((w - G.w0) / G.cell);
  if (j < 0 || j >= G.nw) return -1;
  return i * G.nw + j;
}
// (s,w) 의 칸이 유효하면 그 칸, 아니면 같은 s 행(없으면 가까운 행)의 가장 가까운 유효 칸 — 관측면 가장자리 정점용
function nearestValid(G, s, w) {
  let i = Math.floor(s / G.ds);
  i = G.closed ? ((i % G.ns) + G.ns) % G.ns : Math.max(0, Math.min(G.ns - 1, i));
  const j = Math.max(0, Math.min(G.nw - 1, Math.floor((w - G.w0) / G.cell)));
  for (let di = 0; di < G.ns; di++) {
    for (const sg of di ? [-1, 1] : [1]) {
      let ii = i + sg * di;
      if (G.closed) ii = ((ii % G.ns) + G.ns) % G.ns; else if (ii < 0 || ii >= G.ns) continue;
      let best = -1, bd = Infinity;
      for (let jj = 0; jj < G.nw; jj++) if (G.valid[ii * G.nw + jj] && Math.abs(jj - j) < bd) { bd = Math.abs(jj - j); best = ii * G.nw + jj; }
      if (best >= 0) return best;
    }
  }
  return -1;
}
// 정점 → 집계 칸 번호(격자마다 한 번만 구한다)
export function vertexCells(positions, line, G) {
  const n = positions.length / 3, out = new Int32Array(n);
  for (let v = 0; v < n; v++) {
    const [x, y] = line.to2D([positions[3 * v], positions[3 * v + 1], positions[3 * v + 2]]), [s, w] = line.toSW(x, y);
    out[v] = nearestValid(G, s, w);
  }
  return out;
}
// 칸 값(map) → 정점 색(유효 칸 최대 대비, 같은 색 막대). 칸 없음(−1) = 회색
export function cellColors(cells, map, valid, out = null) {
  let mx = 0;
  for (let k = 0; k < map.length; k++) if (valid[k] && map[k] > mx) mx = map[k];
  const c = out ?? new Float32Array(cells.length * 3);
  for (let v = 0; v < cells.length; v++) {
    const k = cells[v], rgb = k >= 0 && mx > 0 ? ramp(map[k] / mx) : NO_DATA;
    c[3 * v] = rgb[0]; c[3 * v + 1] = rgb[1]; c[3 * v + 2] = rgb[2];
  }
  return c;
}
// 관측면 덧그림 메쉬: 관측면 삼각형을 min(ds, cell) 까지 세분, 관측 방향으로 lift 띄움, 정점별 칸 번호
export function buildObsOverlay(parts, faces, line, G, { maxTris = 200000, lift = 0.05 } = {}) {
  const byPart = new Map();
  for (const f of faces) { if (!byPart.has(f.part)) byPart.set(f.part, new Set()); byPart.get(f.part).add(f.face); }
  const maxEdge = Math.min(G.ds, G.cell), d = line.frame.d, pos = [], tri = [];
  for (const [p, set] of byPart) {
    const s = subdivide(extractFaces(parts[p], set), maxEdge, Math.floor(maxTris / byPart.size)), base = pos.length / 3;
    for (let k = 0; k < s.positions.length; k += 3) pos.push(s.positions[k] + lift * d[0], s.positions[k + 1] + lift * d[1], s.positions[k + 2] + lift * d[2]);
    for (const t of s.triangles) tri.push(t + base);
  }
  const positions = Float32Array.from(pos);
  return { positions, triangles: Uint32Array.from(tri), cells: vertexCells(positions, line, G) };
}

import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const KIND_COLOR = { milky: 0xdfe9f2, clear: 0x8cc8ff, whiteTrans: 0xf2efe6, opaque: 0x8a909c, pcb: 0x2f6b3a, led: 0xffcf3f };
const KIND_OPACITY = { milky: 0.85, clear: 0.35, whiteTrans: 0.95, opaque: 1, pcb: 1, led: 1 };
const SEL_TINT = new THREE.Color(0xffb020), FACE_COLOR = new THREE.Color(0xff5a36), OBS_COLOR = new THREE.Color(0x29d3e0);
// 보기 방향(카메라 쪽). 평면은 z 축과 아주 조금 어긋나게 — up(z) 을 바꾸지 않으려고(OrbitControls 회전축은 생성 때 up 으로 고정)
const VIEW_DIR = { top: [0, -1e-3, 1], front: [0, -1, 0], side: [1, 0, 0], iso: [0.7, -1.1, 0.9] };
const SECTION_N = { x: [-1, 0, 0], y: [0, -1, 0], z: [0, 0, -1] };   // 단면: 좌표 ≤ pos 쪽만 남김

export function createMech3dView(canvas, { onPick, gizmo = null }) {
  const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
  renderer.setPixelRatio(window.devicePixelRatio || 1);
  renderer.localClippingEnabled = true;
  const scene = new THREE.Scene();
  scene.background = new THREE.Color(0x0f1420);
  const persp = new THREE.PerspectiveCamera(35, 1, 0.1, 1e5);
  const ortho = new THREE.OrthographicCamera(-1, 1, 1, -1, 0.1, 1e5);
  persp.up.set(0, 0, 1); ortho.up.set(0, 0, 1);
  let camera = persp, viewName = 'iso', model = { c: new THREE.Vector3(), r: 10 }, orthoHalf = 10;
  scene.add(new THREE.HemisphereLight(0xffffff, 0x404050, 1.0));
  const sun = new THREE.DirectionalLight(0xffffff, 0.8); sun.position.set(1, -1, 2); scene.add(sun);
  const axes = new THREE.AxesHelper(10); scene.add(axes);   // 원점 축: x 빨강 · y 초록 · z 파랑
  const controls = new OrbitControls(camera, canvas);
  controls.enableZoom = true;            // 휠 확대(OrbitControls 가 캔버스 wheel 을 직접 처리)
  controls.screenSpacePanning = true;    // 우클릭·Shift 드래그 = 화면 평면 이동
  const clip = [];                       // 단면 평면(0 또는 1개) — 부품·덧그림 재질이 같은 배열을 공유

  // 회전 축 창(왼쪽 아래 작은 캔버스): 카메라 방향만 따라 도는 축 + X/Y/Z 글자
  let gz = null;
  if (gizmo) {
    const r = new THREE.WebGLRenderer({ canvas: gizmo, antialias: true, alpha: true }), s = new THREE.Scene(), c = new THREE.PerspectiveCamera(40, 1, 0.1, 100);
    c.up.set(0, 0, 1); s.add(new THREE.AxesHelper(1.2));
    const lbl = (t, col, p) => {
      const cv = document.createElement('canvas'); cv.width = cv.height = 64;
      const x = cv.getContext('2d'); x.fillStyle = col; x.font = 'bold 44px sans-serif'; x.fillText(t, 16, 46);
      const sp = new THREE.Sprite(new THREE.SpriteMaterial({ map: new THREE.CanvasTexture(cv) })); sp.position.set(...p); sp.scale.set(0.5, 0.5, 0.5); s.add(sp);
    };
    lbl('X', '#ff5555', [1.5, 0, 0]); lbl('Y', '#55dd55', [0, 1.5, 0]); lbl('Z', '#5599ff', [0, 0, 1.5]);
    gz = { r, s, c };
  }
  const render = () => {
    renderer.render(scene, camera);
    if (gz) { gz.c.position.copy(camera.position).sub(controls.target).normalize().multiplyScalar(4); gz.c.up.copy(camera.up); gz.c.lookAt(0, 0, 0); gz.r.render(gz.s, gz.c); }
  };
  controls.addEventListener('change', render);

  let meshes = [], partsRef = [], kinds = [], sel = null, obsSet = new Set(), overlay = null, obsMesh = null, markers = null;

  function resize() {
    if (canvas.clientWidth === 0) return;
    const w = canvas.clientWidth, h = canvas.clientHeight || 400, a = w / h;
    renderer.setSize(w, h, false);
    persp.aspect = a; persp.updateProjectionMatrix();
    ortho.left = -orthoHalf * a; ortho.right = orthoHalf * a; ortho.top = orthoHalf; ortho.bottom = -orthoHalf; ortho.updateProjectionMatrix();
    if (gz) gz.r.setSize(gizmo.clientWidth || 90, gizmo.clientHeight || 90, false);
    render();
  }
  new ResizeObserver(resize).observe(canvas);

  function colorize(i) {
    const m = meshes[i], p = partsRef[i], col = m.geometry.getAttribute('color');
    const base = new THREE.Color(KIND_COLOR[kinds[i]]);
    const partCol = sel?.part === i ? base.clone().lerp(SEL_TINT, 0.45) : base;
    const T = p.triangles;
    for (let t = 0; t < T.length / 3; t++) {
      const isSel = sel?.part === i && sel.face === p.faceIds[t];
      const c = isSel ? FACE_COLOR : obsSet.has(`${i}|${p.faceIds[t]}`) ? OBS_COLOR : partCol;
      for (let j = 0; j < 3; j++) col.setXYZ(T[t * 3 + j], c.r, c.g, c.b);
    }
    col.needsUpdate = true;
    const op = ghost?.(i) ? Math.min(0.15, KIND_OPACITY[kinds[i]]) : KIND_OPACITY[kinds[i]];   // 투시: LED 선택 중 기구물 반투명
    m.material.opacity = op;
    m.material.transparent = op < 1;
    m.material.depthWrite = !m.material.transparent; m.renderOrder = m.material.transparent ? 1 : 0;
  }

  // 보기 전환: 등각 = 원근, 나머지 = 정투영. 모델 외곽 구(model)에 맞춘다
  function setView(name) {
    viewName = VIEW_DIR[name] ? name : 'iso';
    const { c, r } = model, d = new THREE.Vector3(...VIEW_DIR[viewName]).normalize();
    camera = viewName === 'iso' ? persp : ortho;
    const dist = viewName === 'iso' ? (r / Math.sin((17.5 * Math.PI) / 180)) * 1.1 : r * 4;
    camera.position.copy(c).addScaledVector(d, dist);
    camera.near = r / 100; camera.far = r * 100;
    if (camera.isOrthographicCamera) { orthoHalf = r * 1.1; camera.zoom = 1; }
    controls.object = camera; controls.target.copy(c); camera.lookAt(c);
    resize(); controls.update(); render();
  }
  const fit = () => setView(viewName);

  // parts: 런타임 scene.parts, kindsOf: 부품별 소재 종류 배열, keepCamera: 카메라를 다시 맞추지 않음(LED 위치 보정 등)
  function setParts(parts, kindsOf, { keepCamera = false } = {}) {
    for (const m of meshes) { scene.remove(m); m.geometry.dispose(); m.material.dispose(); }
    partsRef = parts; kinds = kindsOf.slice();
    meshes = parts.map((p, i) => {
      const g = new THREE.BufferGeometry();
      g.setAttribute('position', new THREE.BufferAttribute(p.positions, 3));
      g.setAttribute('color', new THREE.BufferAttribute(new Float32Array(p.positions.length), 3));
      g.setIndex(new THREE.BufferAttribute(p.triangles, 1));
      g.computeVertexNormals();
      const m = new THREE.Mesh(g, new THREE.MeshStandardMaterial({ vertexColors: true, side: THREE.DoubleSide, roughness: 0.6, clippingPlanes: clip }));
      m.userData.part = i;
      scene.add(m);
      return m;
    });
    meshes.forEach((_, i) => colorize(i));
    const box = new THREE.Box3(); meshes.forEach((m) => box.expandByObject(m));
    model = { c: box.getCenter(new THREE.Vector3()), r: box.getSize(new THREE.Vector3()).length() / 2 || 10 };
    axes.scale.setScalar((model.r * 0.3) / 10);
    if (keepCamera) { render(); return; }
    setView(viewName);
  }

  // 바뀐 부품만 재착색
  function setKinds(kindsOf) {
    const old = kinds; kinds = kindsOf.slice();
    meshes.forEach((_, i) => { if (old[i] !== kinds[i]) colorize(i); }); render();
  }
  // over = { obsFaces:[{part,face}], line3d: Float32Array(x,y,z...) | null, arrows:[{pos,axis}] } — 관측면 강조, 라인·LED 발광 화살표
  function setOverlay(over) {
    const prev = obsSet;
    obsSet = new Set((over.obsFaces ?? []).map((f) => `${f.part}|${f.face}`));
    if (overlay) { scene.remove(overlay); overlay.traverse((o) => { o.geometry?.dispose(); o.material?.dispose(); }); }
    overlay = new THREE.Group();
    if (over.line3d?.length) {
      const g = new THREE.BufferGeometry(); g.setAttribute('position', new THREE.BufferAttribute(over.line3d, 3));
      const ln = new THREE.Line(g, new THREE.LineBasicMaterial({ color: 0x29d3e0, depthTest: false }));
      ln.renderOrder = 2; overlay.add(ln);
    }
    for (const a of over.arrows ?? []) {
      const ar = new THREE.ArrowHelper(new THREE.Vector3(...a.axis).normalize(), new THREE.Vector3(...a.pos), 4, 0xffcf3f, 1.2, 0.8);
      ar.traverse((o) => { if (o.material) { o.material.depthTest = false; o.renderOrder = 2; } });
      overlay.add(ar);
    }
    scene.add(overlay);
    const touched = new Set([...prev, ...obsSet].map((k) => +k.split('|')[0]));
    meshes.forEach((_, i) => { if (touched.has(i)) colorize(i); }); render();
  }
  function setSelection(s) { sel = s; meshes.forEach((_, i) => colorize(i)); render(); }
  // 선택 모드별 클릭 대상·투시: pickable(i) = 클릭 가능한 부품, ghostOf(i) = 반투명으로 비출 부품(둘 다 null = 전체/없음)
  let pickable = null, ghost = null;
  function setPickMode(pickableFn, ghostFn) { pickable = pickableFn; ghost = ghostFn; meshes.forEach((_, i) => colorize(i)); render(); }

  // 단면: sec = { axis:'x'|'y'|'z', pos } | null
  function setSection(sec) {
    clip.length = 0;
    if (sec) clip.push(new THREE.Plane(new THREE.Vector3(...SECTION_N[sec.axis]), sec.pos));
    render();
  }
  // 관측면 색지도 덧그림(colormap.buildObsOverlay) — 모양은 격자가 바뀔 때만, 색은 setObsColors 로 자주
  function setObsSurface(geom) {
    if (obsMesh) { scene.remove(obsMesh); obsMesh.geometry.dispose(); obsMesh.material.dispose(); obsMesh = null; }
    if (geom) {
      const g = new THREE.BufferGeometry();
      g.setAttribute('position', new THREE.BufferAttribute(geom.positions, 3));
      g.setAttribute('color', new THREE.BufferAttribute(new Float32Array(geom.positions.length).fill(0.45), 3));
      g.setIndex(new THREE.BufferAttribute(geom.triangles, 1));
      obsMesh = new THREE.Mesh(g, new THREE.MeshBasicMaterial({ vertexColors: true, side: THREE.DoubleSide, clippingPlanes: clip, polygonOffset: true, polygonOffsetFactor: -1, polygonOffsetUnits: -1 }));
      obsMesh.renderOrder = 1.5;
      scene.add(obsMesh);
    }
    render();
  }
  function setObsColors(colors) {
    if (!obsMesh) return;
    const a = obsMesh.geometry.getAttribute('color'); a.array.set(colors); a.needsUpdate = true; render();
  }
  // 설계 점검 표식: ring(원, 화면을 향함) · line(거리선) · tris(새는 면 강조). 깊이 무시(가려도 보임)
  const ringTex = new Map();
  function ringTexture(color) {
    if (!ringTex.has(color)) {
      const cv = document.createElement('canvas'); cv.width = cv.height = 64;
      const x = cv.getContext('2d'); x.strokeStyle = `#${color.toString(16).padStart(6, '0')}`; x.lineWidth = 7; x.beginPath(); x.arc(32, 32, 26, 0, 2 * Math.PI); x.stroke();
      ringTex.set(color, new THREE.CanvasTexture(cv));
    }
    return ringTex.get(color);
  }
  function setCheckMarkers(list) {
    if (markers) { scene.remove(markers); markers.traverse((o) => { o.geometry?.dispose(); if (o.material && !o.isSprite) o.material.dispose(); }); }
    markers = new THREE.Group();
    for (const m of list ?? []) {
      let o;
      if (m.type === 'ring') {
        o = new THREE.Sprite(new THREE.SpriteMaterial({ map: ringTexture(m.color), depthTest: false, transparent: true }));
        const s = (model.r * 0.04 * (m.size ?? 12)) / 12; o.scale.set(s, s, s); o.position.set(...m.pos);
      } else if (m.type === 'line') {
        const g = new THREE.BufferGeometry(); g.setAttribute('position', new THREE.BufferAttribute(Float32Array.from([...m.a, ...m.b]), 3));
        o = new THREE.Line(g, new THREE.LineBasicMaterial({ color: m.color, depthTest: false }));
      } else if (m.type === 'tris') {
        const g = new THREE.BufferGeometry(); g.setAttribute('position', new THREE.BufferAttribute(m.positions, 3)); g.setIndex(new THREE.BufferAttribute(m.triangles, 1));
        o = new THREE.Mesh(g, new THREE.MeshBasicMaterial({ color: m.color, transparent: true, opacity: m.opacity ?? 0.5, side: THREE.DoubleSide, depthTest: false }));
      } else continue;
      o.renderOrder = 3; markers.add(o);
    }
    scene.add(markers); render();
  }

  const ray = new THREE.Raycaster();
  let down = null;
  canvas.addEventListener('pointerdown', (e) => { if (e.button === 0 && e.isPrimary) down = [e.clientX, e.clientY]; });
  canvas.addEventListener('pointercancel', () => { down = null; });
  canvas.addEventListener('pointerup', (e) => {
    if (!down || Math.hypot(e.clientX - down[0], e.clientY - down[1]) > 4) { down = null; return; }
    down = null;
    const r = canvas.getBoundingClientRect();
    ray.setFromCamera(new THREE.Vector2(((e.clientX - r.left) / r.width) * 2 - 1, -((e.clientY - r.top) / r.height) * 2 + 1), camera);
    const h = ray.intersectObjects(pickable ? meshes.filter((m) => pickable(m.userData.part)) : meshes, false)[0];
    // 선택 모드(pickable 지정)에서는 클릭 광선도 넘긴다 — 빈 곳 클릭이어도 { part: null, face: null, ray } (가까운 LED 맞춤용)
    const rr = { o: ray.ray.origin.toArray(), d: ray.ray.direction.toArray() };
    // 클릭 깊이의 화소당 mm(LED 맞춤 반경용) — 정투영은 깊이와 무관
    const H = canvas.clientHeight || 400;
    const wpp = camera.isOrthographicCamera ? (ortho.top - ortho.bottom) / ortho.zoom / H
      : (2 * (h ? h.distance : Math.max(camera.near, controls.target.clone().sub(ray.ray.origin).dot(ray.ray.direction))) * Math.tan((camera.fov * Math.PI) / 360)) / H;
    if (!h) { onPick(pickable ? { part: null, face: null, ray: rr, worldPerPixel: wpp } : null); return; }
    const part = h.object.userData.part;
    onPick({ part, face: partsRef[part].faceIds[h.faceIndex], ray: rr, worldPerPixel: wpp });
  });

  return { setParts, setKinds, setSelection, setOverlay, setPickMode, render, setView, fit, viewName: () => viewName, setSection, setObsSurface, setObsColors, setCheckMarkers };
}

export function renderPartProps(el, m, sel, dbList, h) {
  const p = m.parts[sel.part];
  if (!p) { el.innerHTML = '<div class="mut">부품을 찾을 수 없음</div>'; return; }
  el.innerHTML = `<div class="m3-h">속성 · ${esc(p.name)} <span class="mut">${(p.size ?? []).map((v) => v.toFixed(1)).join('×')}mm · ${(p.volume ?? 0).toFixed(0)} mm³</span></div>${partEditor(p, sel, dbList)}`;
  const i = sel.part;
  el.querySelector('[data-m3-kind]').onchange = (e) => h.onKind(i, e.target.value);
  el.querySelectorAll('[data-m3-mat]').forEach((x) => {
    x.onchange = () => {
      const k = x.dataset.m3Mat;
      let v = x.value;
      if (k === 'T') v = Math.min(1, Math.max(0.01, +x.value / 100));
      else if (k === 'milky') v = Math.min(10, Math.max(0, +x.value));
      else if (k === 'tRef') v = Math.max(0.1, +x.value);
      if (typeof v === 'number' && Number.isNaN(v)) return;
      h.onMat(i, k, v);
    };
  });
  el.querySelectorAll('[data-m3-finish]').forEach((x) => {
    x.onchange = () => {
      const face = x.dataset.m3Finish === 'face' ? sel.face : null;
      const k = x.value;
      h.onFinish(i, face, k ? (FINISH_KINDS[k].hasR ? { kind: k, R: FINISH_KINDS[k].R } : { kind: k }) : null);
    };
  });
  el.querySelectorAll('[data-m3-finishr]').forEach((x) => {
    x.onchange = () => {
      const face = x.dataset.m3Finishr === 'face' ? sel.face : null;
      if (Number.isNaN(+x.value)) return;
      const cur = face == null ? p.finish : resolveFinish(p, face);
      h.onFinish(i, face, { ...cur, R: Math.min(1, Math.max(0, +x.value / 100)) });
    };
  });
}

// 3D 기구 — 광원 · LED · 관측면 · 목표 속성 편집기 (spec 2026-10-14 §4·§5, 2026-10-15 m3-cad-ui §2). 상태 없음.
// P3 의 renderLightPanel 을 피처 트리 노드별로 나눴다. 계산 버튼·결과 표시는 자동 점진 계산(결과 패널·상태 띠)으로 옮김.
const esc = (s) => String(s ?? '').replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/"/g, '&quot;');
const num = (v, d = 1) => (Number.isFinite(v) ? v.toFixed(d) : '-');
const numIn = (v, d) => (Number.isFinite(v) ? v.toFixed(d) : '');   // number input 값(빈칸 허용)
const sel = (v, cur) => (v === cur ? 'selected' : '');
const autoPh = (v) => (Number.isFinite(v) ? `자동 ${v.toFixed(1)}` : '자동');
// 숫자 입력 읽기: 빈칸 → null, min/max 속성으로 자르기
function readNum(x) {
  if (x.value.trim() === '') return null;
  let v = +x.value;
  if (!Number.isFinite(v)) return null;
  if (x.min !== '') v = Math.max(+x.min, v);
  if (x.max !== '') v = Math.min(+x.max, v);
  return v;
}
const pickBtn = (ui, mode, label) => `<button data-lp-pick="${mode}" class="${ui.pick === mode ? 'on' : ''}">${label}</button>`;
const on = (el, q, ev, fn) => el.querySelectorAll(q).forEach((x) => x.addEventListener(ev, () => fn(x)));

// 3D 계산 Worker 풀 — main.js(P3) 에서 옮김. 0번 Worker 는 라인 인식에도 쓴다. 필요한 만큼 늘리고 유지(L2 표 재적재 방지).
// ports() = 점진 계산 제어기용 포트 [{ send(msg) → Promise<reply> }] (K = 코어 수 − 1, 1~8)
const TIMEOUT = 10 * 60 * 1000;

export function createPool({ dbLists, onStatus = () => {} }) {
  const pending = new Map(), pool = [];
  let reqId = 0;
  function onMessage(e) {
    const d = e.data;
    if (d.id == null) { if (d.error) onStatus(`계산 Worker 초기화 실패: ${d.error}`); return; }
    const p = pending.get(d.id);
    if (p) { pending.delete(d.id); clearTimeout(p.timer); d.error ? p.rej(new Error(d.error)) : p.res(d); }
  }
  // Worker 를 풀에서 빼고 종료, 그 Worker 에 걸린 호출은 모두 실패 처리(다음 호출 때 새로 만든다)
  function drop(w, msg) {
    w.terminate();
    const k = pool.indexOf(w); if (k >= 0) pool.splice(k, 1);
    for (const [id, p] of pending) if (p.w === w) { pending.delete(id); clearTimeout(p.timer); p.rej(new Error(msg)); }
  }
  function killAll(msg) { for (const w of pool.slice()) drop(w, msg); }
  function spawn() {
    const w = new Worker(new URL('../../engine/mech3d/mc3d-worker.js', import.meta.url), { type: 'module' });
    w.onmessage = onMessage;
    w.onerror = (e) => { const msg = `계산 Worker 오류: ${e.message ?? e}`; onStatus(msg); drop(w, msg); };
    w.postMessage({ type: 'init', l2Base: new URL('../../engine/l2/data/', import.meta.url).href, db: dbLists() });
    return w;
  }
  const worker = (k = 0) => { while (pool.length <= k) pool.push(spawn()); return pool[k]; };
  const call = (w, msg) => new Promise((res, rej) => {
    const id = ++reqId;
    const timer = setTimeout(() => { if (pending.has(id)) drop(w, '계산 시간 초과(10분) — 다시 시도하세요'); }, TIMEOUT);
    pending.set(id, { res, rej, w, timer });
    w.postMessage({ ...msg, id });
  });
  const size = () => Math.max(1, Math.min(8, (navigator.hardwareConcurrency ?? 4) - 1));
  const ports = () => Array.from({ length: size() }, (_, k) => ({ send: (msg) => call(worker(k), msg) }));
  return { worker, call, killAll, ports };
}

    const parts = ledPartsNow(M), face = refineEmitterFace(parts[st.ref.part], st.ref.face), changed = face !== st.ref.face;

// 반환 = LED STEP 부품 번호 기준 { part, face, snapped } | null (nMech = 기구 부품 수, 그 이상 번호가 LED STEP 부품)
export function snapLedPick(M, s, nMech, needFace) {
  const parts = ledPartsNow(M);
  // 직접 맞힌 면은 평행한 가장 바깥 면으로 보정(몸체 윗면 → 렌즈 윗면). pickLedNearRay 결과는 이미 보정됨
  const direct = (i) => ({ part: i, face: needFace && parts ? refineEmitterFace(parts[i], s.face) : s.face, snapped: false });
  if (!parts || !s?.ray) return s?.part != null && s.part >= nMech ? direct(s.part - nMech) : null;
  const vol = (i) => parts[i].volume ?? meshStats(parts[i]).volume;
  const big = parts.reduce((b, _, i) => (vol(i) > vol(b) ? i : b), 0), hit = s.part != null && s.part >= nMech ? s.part - nMech : null;
  if (hit != null && (hit !== big || parts.length < 2)) return direct(hit);
  const r = pickLedNearRay(parts, parts.map((_, i) => i).filter((i) => i !== big), s.ray.o, s.ray.d, snapRadius(s.worldPerPixel), needFace ? big : -1);   // 반경 = max(5mm, 14px), 발광면 = 윗면 발광 가정
  if (!r || (needFace && r.face < 0)) return null;
  return { ...r, snapped: true };
}
// 계산에 쓸 발광점: LED STEP = 인식된 것 중 확인 필요·제외 뺀 것, 직접 배치 = 관측 라인 위 배치((라인, 설정, 기구) 별 캐시). 오류는 던진다
export function currentEmitters(M, line) {
  const L = M.light;
  if (L.kind === 'step') { const ex = new Set(L.step?.excluded ?? []); return (L.step?.emitters ?? []).filter((e) => !e.needsCheck && !ex.has(e.part)); }
  if (L.kind === 'manual' && line) {
    const key = JSON.stringify(L.manual);
    if (!manCache || manCache.line !== line || manCache.key !== key || manCache.rt !== getMech3d()) {
      let em = null, err = null;
      try { em = manualLeds(line, L.manual, getMech3d()); } catch (e) { err = e; }
      manCache = { line, key, rt: getMech3d(), em, err };
    }
    if (manCache.err) throw manCache.err;
    return manCache.em;
  }
  return [];
}
// LED 몸체 외곽 상자(점검 ① 간섭) — LED STEP 의 인식된 LED 중 제외하지 않은 것
export function ledBodies(M) {

  if (!st || !parts) return [];
  const ex = new Set(st.excluded ?? []);
  return (st.leds ?? []).filter((i) => !ex.has(i) && parts[i]).map((i) => { const b = bounds(parts[i].positions); return { led: i, lo: b.slice(0, 3), hi: b.slice(3) }; });
}

function onCalc(snap) {

function importMech3d(file) {
  const say = (t) => { if (m3app.isMounted()) m3app.setStatus(t); else $('#timing').textContent = t; };
  say(`${file.name} 읽는 중…`);

    const w = new Worker(new URL('./engine/mech3d/mech3d-worker.js', import.meta.url), { type: 'module' });
