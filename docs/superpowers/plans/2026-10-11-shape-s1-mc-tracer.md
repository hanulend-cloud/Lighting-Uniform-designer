# S1 — 형상 몸체 MC 기준 추적기 (spec 2026-10-10 §4.1, §5)

목표: 2.5D 높이맵 몸체(투명/밀키)의 기준 광선추적기 `src/engine/shape/mc-body.js` + 검증 VS1·VS2·VS3·VS6 (`test/shape-mc.mjs`).

## 설계 결정
- 기하: 높이맵 셀 = 사각 패치, 꼭짓점 높이 = 인접 마스크 셀 중심값 평균(선형 함수는 내부에서 정확) → 대각선 2삼각형(평면).
  셀 경계 DDA 로 윗면·바닥 평면 교차, 마스크 경계 = 수직 측벽. 캐비티 측벽 = 수직 평면(z ≤ 깊이), PCB = z=0.
- 계면: Fresnel(비편광)·TIR, **가중 분기**(반사 가지는 스택, w < 1e-3·w0 이면 러시안 룰렛 1/10) — 상면 탈출은 부분 탈출과 동일.
- 체적: 자유행로 ~ μs, 흡수 = exp(−μa·s) 가중(장부 기록), 위상 = HG(g) 또는 표 샘플러(Mie).
- 광원: LED 칩 면 균일 위치, 배광 rel(θ)(cos^m 정확 역변환 / Gaussian 표), 광자 가중 = I0·∫rel dΩ / (광자/LED).
- 출력: 상면 출사도 맵(배치별 → 잡음 σ), 출사각 히스토그램, 직진(무산란·무반사) 맵, 에너지 장부(룰렛 손익 포함 → 장부 폐합 정확).
- 결정론 단일 광선 `traceRay`(VS3): 투과 가지만 따라가며 사건(계면·법선·cosI·R·출사방향) 기록.

## 검증 (기준은 사전 고정)
- VS3: 쐐기(윗면 경사 α) 수직 입사 → 편향각 asin(n sinα)−α, α>θc 이면 TIR(R=1), R = 독립 s/p 식 — ≤1e-9 (Float64 높이맵).
- VS1: 큰 평판·점광원·PCB 흡수 → 반경 등광속 bin 별 직진 출사도 vs 반해석(2계면 Fresnel·흡수) ≤1%,
  전체(내부 다중반사 급수 포함) ≤1%.
- VS2: 장부 폐합 ≤1e-9(기록 정확), 룰렛 순손익 ≤0.5%.
- VS6: 밀키 평판 LED 배열(열린 영역) 중심 피치셀(접어서 통계) vs L2 PSF 중첩 — 평균 ≤3%, min/max ≤2%p.

## 실행 기록 (2026-10-11)
- 가중 분기를 모든 계면에 쓰면 밀키에서 가지가 폭증(광자당 수 ms) → spec 대로 상면만 부분 탈출, 나머지는 확률 선택. 셀 내부 빠른 경로(결과 비트 동일, −28%).
- MC 자체 검증: 펜슬빔 경사 입사에서 형상 MC = 슬래브 MC(adding-doubling 대조 완료) — T ≤1%, 측방 시프트 1.140 vs 1.140mm,
  반경 분포 bin 별 일치. LED + 슬래브 MC 독립 합성과 형상 MC 반경 출사도 일치(≤3%).
- **VS6 가 L2 PSF 결함을 찾음**(Milky 3, 피치 = 깊이: 균일도 PSF 89.0% vs MC 93.9%, 4.9%p):
  ① 입사각을 9개 행 중 최근접 행에 통째 배정 → 밴드 경계 계단, ② 경사 입사의 출사 중심 바깥 이동 무시
  (작은 각도도 r·(1+t/(n·h)) 확대 → 중심 과집중). 수정: `table.bandSplit` 선형 보간, PSF 에서 셀별 기하 시프트
  (직진 t·tanθ', 산란 = 행별 전방 비 × t·tanθ'), 밀도 역매핑(야코비안), 반경 분포 2차 모멘트 보존 축소.
- 검증 스크립트 함정: 성긴 부분표본 annulus 바이닝이 중심 bin 면적을 +13% 편향 → 극좌표 등면적 표본으로 교체.
- l2-integration "PSF 중첩 = 전체 solve" 는 기계장치 동등성 검사라 시프트를 끄고 비교(`setLateralShift(false)`).
- 본 실행 결과: VS3 8.9e-16 / 측벽 5.6e-17, VS1 직진·전체 bin 최대 0.50%(4e6 광자), VS2 폐합 3.6e-12·복잡 형상 1.8e-13,
  VS6 Milky 3 평균 0.50%·균일도 0.99%p, Milky 7 평균 0.16%·균일도 **1.78%p**(σ 0.27, 한도 2%p 근접 — PSF 가 약간 더 균일, 고 Milky 전방비 근사 여지).
- 기존 테스트: npm test 31/31, test:l2 전체 통과(solvePerLevel 2.7s, solveCombo 0.25s).
- `npm run test:shape`(빠른 판), `npm run test:shape-full`(VS6 16 worker, ~8분).
