**Goal:** LED 를 폭 방향 2열(±δ)로 놓을 수 있게 하고(직접 배치·LED STEP 가상 배치), 자동설계 ② 가 열 수·열 간격까지 골라 폭 균일도를 확보하게 한다.

### Task 1: 엔진 — 열 배치
- `placement.js`: `ledAtS(line, s, opts, rt, w = 0)`(w 오프셋: `line.fromSW(s, w)`), `manualLeds(line, { count, pitch, rows = 1, rowGap = 0, … })` → rows 2 면 같은 s 에 w = ±rowGap 두 개(순서: s 오름차순, 각 s 에서 −δ, +δ). rowGap 은 라인 반폭 − 0.5 mm 로 제한.
- `virtual-leds.js`: `virtualLayout({ …, rows = 1, rowGap = 0 })` — 기준 LED 의 w0 에 ±rowGap 더한 위치로 몸체·발광점 복사(rows 2 → 2·count 개). `stepLayoutOf` 가 virtual.rows/rowGap 전달.
- `basis.js`: `candidateGrid(line, { sStep = 2, wOffsets })` → [{s, w}], `layoutMap2(cand, maps, positions /* [{s,w}] */)` — w 는 후보 격자에 정확히 있는 값만(없으면 오류), s 는 같은 w 줄 안에서 선형 보간. `searchLeds2({ G, obs, line, cand, maps, rowsOptions:[1,2], gaps, pitchRange, nMax, emitted })` — 총 LED 수 오름차순(1열 n = 총수, 2열 n = 총수/2), 같은 총수면 1열 먼저, 통과 첫 총수에서 그 총수의 최고 피치·δ. 불가 시 가장 가까운 안(기존 nearestRow 규칙, 총수 기준). 결과 { n(열당), rows, rowGap, pitch, total, … }.
- defs.js migrate: manual.rows/rowGap, step.virtual.rows/rowGap 기본·정리.
- 시험: 열 위치·순서·제한, 가상 배치 2열 몸체 위치, 2D 보간 합 = 직접 합, 합성 지도에서 1열 불가·2열 가능 장면을 해석적으로 만들어 2열·최소 총수를 찾는지, 1열로 되면 1열을 고르는지.

### Task 2: 화면 연결
- 직접 배치 패널: 열 수(1/2)·열 간격(mm) 입력. LED STEP 가상 배치 행: 열 수·열 간격. 트리 배지 `2열 × 10개`.
- 자동설계 ②: io.basis 가 candidateGrid(s 2 mm × wOffsets = [0, ±0.2W, ±0.27W, ±0.33W]) 로 후보를 추적(직접 배치 = ledAtS(…, w), LED STEP = virtualEmittersAt 에 w 지원), `searchLeds2` 사용, 설계 d 에 rows·rowGap, designScene·adApply·adRevert 반영, 비교표 문구, sameDesign 에 rows·rowGap.
- 시험: 패널·배지·비교표 문구, sameDesign.
