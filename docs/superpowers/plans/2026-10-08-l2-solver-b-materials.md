# L2 Solver B — Measured Materials (fit · DB · advanced menu) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** spec rev.4 §6.1 (measured BTDF/BRDF → μs·g·μa → Milky), §6.3 (materials DB, Milky derived from μs'),
§6.4 (advanced "상세 property" menu: view / DB input / export), V6, V9, SV2, SV8, SV9, plus the B-deferred items
(identifiability rules, absorption-kernel correlation).

**Architecture:** fitting runs on the shipped slab table (no MC at runtime): coarse grid over (log μs', g[, log μa])
then Nelder–Mead, objective = weighted T, R, haze, HPA and normalized angular-intensity shape at every measured
thickness. A material entry stores raw measurements + fitted μs', g, μa (canonical); Milky is always derived.
Selecting a material makes L2 use its μs', g, μa instead of the abstract (g=0.9, κ) material.

**Reference data:** Covestro Makrolon® DQ brochure (2 mm): DQ5122 HPA 19° T 85%, DQ5142 43° 65%, DQ5162 56° 57%
→ built-in `status:'datasheet'` entries (fitted with μa fixed — datasheet has no R).

## Task B1 — `src/engine/l2/fit.js`
- `parseAngleCsv(text)` → `[{theta, v}]` (comma/tab/semicolon, header skipped, sorted).
- `predictSample(table, mat, t)` → `{T, R, Tb, Ts, hpa, haze, I(θ) per bin}`; haze = scattered beyond 2.5° / T.
- `measuredIntensity(sample)` → normalized intensity on the comparison grid (5–80°), from `btdf` (×cosθ) or `intensity`.
- `fitMaterial(table, entry, opts)` → `{musR, g, mua, n, milky, free:{g, mua}, residuals, V6, V9}`;
  identifiability: g free only if angular data and max τ' < 8; μa free only if R measured or ≥ 2 thicknesses.
- V6: refit reproduces each sample (T ±2%p, HPA ±2°, R ±2%p, curve RMS ≤ 5%).
- V9 (≥ 2 thicknesses): leave-one-thickness-out prediction T/R ±3%p, HPA ±3°.

## Execution notes (2026-10-08)

- **Table g range extended 0.95 → 0.99** (g grid {0.6,0.8,0.9,0.95,0.98,0.99}): Makrolon DQ datasheet values could not be
  fitted at g ≤ 0.95 (all fits hit the bound). Bead-diffused PC is extremely forward-scattering. AD references added for
  g 0.98/0.99 with 32 quadrature points (16 vs 32 agree within 0.002; 64 numerically unstable). Rebuild: 5760 cells, 98 min, 6.7 MB.
- **Absorption–kernel correlation implemented** (not deferred): measured with direct MC, absorption narrows the scattered
  spot by ~5% at realistic μa (high g/τ') and 15–17% at 4×, above the 2% threshold. Per-path-bin Σw·r² added to the table;
  `radScale` (exact RMS ratio) scales the kernel. Check: 0.9460 vs direct MC 0.9426. τ' > 20 (diffusion) not scaled — listed in assumptions.
- **V4 threshold = Bonferroni** over 210 comparisons (z = 3.51 instead of 3): one 3.04σ HPA fluctuation at g 0.98 τ' 12
  is an expected chance event at 3σ with 210 tests (≈0.28 expected).
- **HPA < 5° excluded from comparisons**: when the unscattered peak dominates, HPA jumps 1°↔48° for tiny ballistic changes.
- **DQ fits:** DQ5142 (μs' 0.292/mm, g 0.98, Milky 2.99) and DQ5162 (0.478/mm, 0.98, Milky 3.60) pass V6.
  **DQ5122 fails V6 — correct outcome:** with an HG phase function the T–HPA relation is nearly g-independent
  (similarity law); at HPA 19° the model reaches only T ≈ 75% (vendor 85%). A narrow forward lobe with low loss needs a
  Mie (large-bead) phase function → phase C. The UI shows it as "보정 불일치".
- Synthetic recovery (direct MC, no table): μs' within 1.5%, g within 0.04, μa exact; V6/V9 pass.
