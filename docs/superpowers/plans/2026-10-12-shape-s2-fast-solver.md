# S2 — 형상 몸체 빠른 solver (spec 2026-10-10 §4.2, VS4·VS5·VS7)

배경: 자동탐색은 피치 이분탐색 등으로 평가를 수십 회 반복 → 평가 1회 ≲100ms 목표. 형상 1광선 ≈2µs(실측).

## 분할
- **S2a 투명 형상**(L3·L4·불러온 몸체, L2 꺼짐): 조도(출사도) 경로를 edgeBoost 스칼라 대신 광선관 추적으로.
- **S2b 밀키 형상**(L2 + 형상): 국소 슬래브(국소 두께 τ'·국소 갭) 앵커 PSF — 현 "평균 두께" 근사 대체.
- **S2c 파라미터·휘도**: L3 = 두께 변화(오프셋·테이퍼) 의미 이식(불러온 몸체 공통), 카메라 휘도 경로를 높이맵 바닥으로 일반화,
  L1 평판 해석 커널을 굴절 정확(VS1 반해석)으로 맞춰 L1 ↔ 평탄 L3 일관성, 기존 테스트 재기준(근거 기록).

## S2a 설계
- `shape/body-geom.js`: 활성 레벨 → 툴 좌표 높이맵(캐비티 벽 사각형 전체). 생성 평판 = 기존 정본 수식(l3BotZAt / l4BotZAt,
  "L4 가 L3 대체"), 불러온 몸체 = 높이맵 재표본 + Δ_L4 = l4BotZAt − (depth − L1 두께). 윗면 평탄(생성) / 불러온 윗면.
- `shape/fast-body.js`: 앵커 LED 별 광선관 PSF → 전 LED 중첩.
  - 광선관: 등광속 θ 고리 × 균일 φ. 꼭짓점 광선 = 주경로(투과, TIR 이면 반사) 결정론 추적, 서명(사건 순서) 같고 상면 탈출이면
    출사 사각형을 래스터(균일 밀도), 아니면 2단 세분 후 점 분배. 사각형 중심 광선은 가지 전체(Fresnel 반사·내부 반사·측벽)를
    가중으로 추적(에너지 1e-3 절단) — 2차 출사는 점 분배, 아래로 나간 빛은 PCB 지도.
  - PCB 재순환 1회: ρ_b·PCB 지도 ⊛ 갭 커널 P_h × 확산 투과 T_d (닫힌 근사, 가정 패널).
  - 앵커: LED 격자 인덱스 {0,1,중앙…,n−2,n−1}(내부는 형상 변화에 따라 간격) — 각 LED 는 같은 등급·최근접 앵커 PSF 를 평행이동.
    벽(캐비티 Fresnel)·몸체 외곽은 앵커 추적에 실제로 포함.
- 통합: computeField — 형상 활성 + L2 꺼짐이면 fast-body 경로(edgeBoost 미적용). L1 단독은 기존 경로(S2c 에서 정리).

## 검증 (기준 사전 고정)
- 평판 = VS1 반해석 ≤1% (직진·전체).
- VS4: 각도 격자 2배 → 중심부 평균·균일도 변화 ≤1% / ≤1%p.
- 앵커 근사 vs 전 LED 추적: 중심부 평균 ≤1%, 균일도 ≤1%p.
- VS7: fast vs S1 MC (테이퍼 평판, L4 포켓, 돔·리브 불러온 형상) — 균일도 ≤2%p, 평균 ≤3%.
- VS5: 독립 Python 추적기(압출 프로필, 선광원) — 출사 프로파일 ≤2%.
- 성능: 평가 1회(100 LED, 101² 격자) ≤150ms.

## 실행 기록 S2a (2026-10-12)
- 광선관 PSF: 꼭짓점 주경로(서명 일치 → 매개공간 등광속 표본 래스터, √u 보간, 노드 2칸 초과·꼭짓점 고리 세분), 2차 가지는
  꼭짓점 4 + 중심 1 구적으로 주경로가 못 운반한 몫을 정확히 보존(중심 1개만 쓰면 렌즈 경사에서 에너지 누수). PSF 는 평가 간격/2
  격자 + 분산 맞춤 텐트(MC 쌍선형 분배와 같은 필터 — 2중 텐트는 L4 균일도 +7%p 왜곡).
- 재순환: PCB Lambertian 점광원 PSF 를 실제 형상으로 추적해 PCB 지도와 합성곱(주기 형상은 단위 셀 위상별), 이후 반사 기하급수.
- 장면 방식(형상별): L1 평판 = 열린 영역 단일 PSF + 캐비티 벽 거울(노드별 Fresnel), L3 테이퍼 = 고정 앵커 격자 쌍선형(피치 무관
  → 평가 간 캐시), L4 주기 = LED 등급(벽 0·1열·내부) 앵커를 실제 장면(외곽 측면 포함)에서(열린 영역은 경사에 갇힌 빛이 측면에서
  되돌아오는 몫을 잃어 −4%), 불러온 몸체 = LED 별 실제 장면(국부 리브를 앵커 평행이동하면 −8%p).
- **S1 버그 발견·수정**: 몸체 광선이 격자 끝(외곽 측면)에 닿을 때 셀 경계 = 격자 끝 부동소수 등호로 측면을 놓침(20만 중 2.5%) →
  산란 매질에서 광자가 기하 밖에서 계속 산란(복잡 형상 흡수 7.0% → 실제 2.8%). 회귀 시험 추가(VS3).
- 속도: 셀 높이 범위·8×8 블록 건너뛰기(결과 동일 확인), 생성 형상 셀 = 형상 스케일. 2단 정밀도(탐색 search / 확정 full) +
  레벨별 참고표는 경량 대리 모델로 탐색 후 full 1회 재검증.
- 검증(본 실행): 평판 vs 반해석 0.89%, VS4 수렴 ≤0.22%·0.4%p, VS7 vs MC: L1 0.65%p·0.1%, L3 0.16%p·0.2%, L4 1.06%p·2.2%,
  돔·리브 0.93%p·0.1%. 기존 테스트 전부 통과.
- 남은 일: 속도(조합 탐색 L3 3s·L4 10s, 레벨 표 14.6s — 이전 ~3s), VS5(독립 Python), S2b(밀키+형상), S2c(L3 두께 변화 의미·카메라 휘도·L1 정합).

## 실행 기록 — 계산 Worker (2026-10-12, 사용자 결정: 설계안 광선관 + 백그라운드)
- `src/engine/solve-worker.js`: 조합 탐색 → 판정 필드(full) → 히트맵 → [결과 전송] → 레벨별 표(단독 행 캐시 보관) → [표 전송].
  L2 응답표·소재 DB·불러온 몸체를 Worker 에도 적재(메인은 L2 카드 표시용 보유). 진행: solver 평가마다 훅(4회/초).
- main.js: run() = Worker 요청(진행 중 새 입력은 최신 1개만 대기 후 이어서), 결과로 렌더. 히트맵도 Worker 요청.
- 형상 경로의 고해상(히트맵 0.5mm) 요청은 ~1mm 격자로 계산 후 쌍선형 업샘플(PSF 크기 ∝ 1/간격²).
- 브라우저 확인(기본 사양 L1+L3): 설계안·히트맵 8.5s(첫 로드, 응답표 적재 포함), 레벨별 표 포함 32s, 계산 중 화면 응답 유지,
  계산 중 깊이 14→10 변경 시 최종 결과 = 10mm(144개, 중심 80.5%), 콘솔 오류 없음.
